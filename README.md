# 前線基地コマンダー

iPhone のブラウザで遊べる、一人用の軍事基地育成ゲームです。
**`index.html` の1ファイルだけ**で動きます(広告なし・外部との通信なし・日本語・縦画面向け)。

## 遊び方

1. **基地**: 3×3 の区画(中央が司令部)に施設を建てて強化します。費用は資金と鋼材。
2. **出撃**: 敵の編成を見て、相性の良い兵種と指揮官で部隊を組み、出撃します。戦闘は自動(×1/×2/×4・スキップ)。
   - **陣取り地図**: 出撃画面の上は六角形のマスでできた地図です。1段が1ステージで、制圧した段までが自軍の領土(緑)、
     その先が敵の領土(赤)です。マスをタップするとそのステージを選べます(まだ行けない段は選べません)。
     なぞると地図を上下に動かせます。新しいステージを初めて制圧すると、地図に戻ったときにそのマスが緑に変わる演出があります。
   斜め上から見下ろした戦場で、兵士の群れ(部隊)が前線をはさんで撃ち合います。部隊の上の数字は残りの兵数、
   緑と赤の線が前線で、優勢な側へ押し込んでいきます。勝つと敵陣まで押し上げて占領します。
   地形はステージによって草原・雪原・砂漠に変わります。
   - **広い戦場**: 両軍の陣地・村・池・林・拠点の旗がある広いマップです。開始時は戦場全体を見せてから前線に寄ります。
     指でなぞると見回し、2本指で拡大・縮小できます(右上の「戦況を追う」で元の視点に戻ります)。
     拠点の旗は前線のどちら側にあるかで色が変わり、勝つと前線が敵の陣地まで押し上がって建物を占領します
     (拠点や建物は見た目の演出で、勝敗の計算には影響しません)。
   - **大軍どうしの戦い**: 各部隊は数千人規模の兵士の群れで、どの敵を狙っているかが緑(自軍)・赤(敵)の線で見えます。
     自軍は川の手前の陣地から橋を縦一列で渡って前線へ向かいます。敵の前には土のうの壁があり、
     前線が押し上がったり近くで爆発が起きたりすると崩れます。敵陣の家や見張り塔も、砲撃が続くと壊れて燃えます。
     指揮官「雷門 ハヤト」の一斉射撃は、後方の陣地からのミサイル攻撃になります。
   - **自動 / 手動の切替**: 出撃画面の「戦闘 自動/手動」か、戦闘中の「AUTO」ボタンでいつでも切り替えられます。
     手動では、自軍の部隊から敵の部隊へドラッグ(またはタップ→敵をタップ)すると、その敵を集中攻撃します。
     何もない所へドラッグすると自由攻撃に戻ります。指揮官スキルは画面下のボタンで好きなタイミングで発動します
     (手動では押さないと発動しません)。予想勝率は自動戦闘の場合の値です。
   - **配置の指示(手動)**: 自軍の部隊を前線の先へなぞると「前進」(与えるダメージ・受けるダメージが増え、敵に狙われやすい)、
     前線の後ろへなぞると「後退」(与えるダメージは減るが、受けるダメージが大きく減り、狙われにくい。砲兵は後退しても威力が落ちない)。
     部隊の上の ▲(前進)・▼(後退)が今の指示です。AUTO に戻すと解除されます。
   - **途中参戦(増援カード)**: 戦闘中は増援ポイントが少しずつたまり、たまると画面下のカードで予備の部隊を戦場に呼べます。
     タップするとおまかせの列に、戦場へドラッグすると置いた列に出ます。増援の数は司令部レベルで1〜3部隊
     (Lv1:1・Lv5:2・Lv10:3)、強さは通常の部隊の6割です。敵もステージ6から増援を出してきます。
     AUTO のときは、生き残っている敵に相性の良い兵種が自動で出ます(予想勝率にも増援が含まれます)。
   - **コイン回収**: 勝つと戦場にコインが散らばり、画面上の報酬に向かって集まります。基地で生産施設の「回収」を押したときも、
     資金・鋼材が上の表示へ飛んでいきます。
   - 戦闘の途中で閉じた場合、開き直すと残りは自動で戦った結果が反映されます。
3. **兵器**: 研究所を建てると、兵種ごとに武装を開発・強化できます(下の「兵器」タブ)。
   - 各兵種に **武器**(攻撃力 +5%/Lv)・**防護**(耐久 +5%/Lv)・**特殊**(苦手な敵へのダメージ)の3系統があります。
   - 5レベルごとに新型を**開発**します。名前は実在の兵器・装備から取っています(おおむね年代順。性能はゲーム用の数値)。
     - 戦車の武器: 75mm M3戦車砲 → 88mm KwK36 → 105mm L7 → 120mm L44 → 120mm L55 → 130mm Rh-130 → 改 → 改二…
     - 歩兵の武器: 三八式歩兵銃 → M1ガーランド → StG44 → AK-47 → M16A2 → HK416 → 20式小銃
     - 歩兵の特殊(対戦車): 九九式破甲爆雷 → M1バズーカ → パンツァーファウスト → RPG-7 → AT4 → ジャベリン
     - 対戦車兵の武器: ボーイズ対戦車銃 → パンツァーシュレック → M40無反動砲 → カール・グスタフ → TOW → コルネット → 中距離多目的誘導弾
     - 砲兵の武器: M101榴弾砲 → sFH18重榴弾砲 → M114榴弾砲 → FH70榴弾砲 → M777榴弾砲 → M270 MLRS → M142ハイマース
     - 防護は 防弾ベスト・装甲車・戦車の装甲・自走砲の車体、特殊は 機関銃・対装甲弾 など
     開発には **設計図** が必要で、設計図は戦闘に勝つと手に入ります(先のステージほど多く、ボス戦と初クリアは2倍)。
     開発と開発の間の**強化**は資金・鋼材だけでできます。武装のレベル上限は 研究所Lv×2 です。
   - 特殊は苦手な相性を打ち消す装備です(歩兵の対戦車兵器 → 戦車に、戦車の機関銃 → 対戦車兵に、砲兵の対装甲弾 → 戦車に、など)。
     上げるほど伸びは小さくなり、苦手の半分を打ち消すところ(例: 戦車→対戦車兵 ×0.6 が最大 ×0.8)が上限なので、
     相性で編成を考える意味は残ります。
     戦闘では、特殊装備が効いた攻撃に「特効!」と出ます。
   - 武装は増援の部隊にも反映されます。ステージが進むと敵も武装の普及に合わせて少しずつ強くなります。
4. 勝てば資金・鋼材・設計図・経験値。**負けても兵は失いません。** 勝てないときは前のステージで稼いで強化しましょう。
   - **稼ぎにおすすめ**: 負けたときの画面と出撃画面のボタンで、「予想勝率80%以上で勝てるステージのうち、
     1戦あたりの稼ぎ(勝率×報酬)がいちばん多いステージ」を探して、おまかせ編成にします。
     報酬2倍のボス戦が選ばれることもあります。

進行は自動で保存され、ブラウザを閉じて開き直すと続きから再開します(戦闘の途中で閉じても結果は反映されます)。
ターン数や期限による終了はなく、ステージは上限なく続きます。

### 施設

| 施設 | 役割 |
|---|---|
| 司令部 | ほかの施設のレベル上限(司令部Lv×2)と、部隊の枠(2→最大6)を上げる |
| 補給所 / 製鋼所 | 資金 / 鋼材を生産。閉じている間も上限まで貯まり、「回収」で受け取る |
| 倉庫 | 放置で貯まる上限の時間を延ばす(2時間 + 1時間/Lv、最大24時間) |
| 兵舎 / 対戦車陣地 / 戦車工場 / 砲兵陣地 | 歩兵 / 対戦車兵 / 戦車 / 砲兵 を解放・強化 |
| 研究所 | 全兵種をまとめて強化。兵器開発を解放し、武装のレベル上限(研究所Lv×2)を上げる |

### 兵種の相性(攻撃側 → 防御側のダメージ倍率)

| | 歩兵 | 対戦車兵 | 戦車 | 砲兵 |
|---|---|---|---|---|
| **歩兵** | ×1.0 | ×1.5 | ×0.6 | ×1.5 |
| **対戦車兵** | ×0.75 | ×0.8 | **×2.2** | ×0.75 |
| **戦車** | ×1.5 | ×0.6 | ×1.0 | ×1.5 |
| **砲兵** | ×1.5 | ×1.5 | ×0.6 | ×1.0 |

### 指揮官(ヒーロー)

| 指揮官 | 得意兵種 | 固有スキル | 着任 |
|---|---|---|---|
| 鬼塚 剛 | 歩兵 | 突撃: 味方全体の攻撃力 +50%(6秒) | 最初から |
| 鉄崎 ミナ | 戦車 | 装甲: 味方全体の被ダメージ半減(6秒) | ステージ3クリア |
| 白鷹 レン | 対戦車兵 | 一撃必中: 相性の良い敵1体に攻撃力400%の必中弾 | ステージ8クリア |
| 雷門 ハヤト | 砲兵 | 一斉射撃: 敵全体に攻撃力120%の砲撃 | ステージ15クリア |

得意兵種を率いると大きく強くなり、戦闘で経験値を得てレベルアップします。

## iPhone で遊ぶには

HTML ファイルを Web 上に置いてブラウザで開くのがおすすめです。

- **GitHub Pages**: リポジトリの Settings → Pages で、Branch を公開したいブランチ・フォルダを `/ (root)` にして保存すると、
  `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。
- Safari で開いたら、共有ボタン →「ホーム画面に追加」で全画面のアプリのように遊べます(保存データも消えにくくなります)。
- メニュー(右上)の「引き継ぎコード」でバックアップ・復元ができます。

## テスト

バランス確認と iPhone 画面での動作確認を自動テストにしています。

```sh
node tests/balance.test.js            # ルールの確認 + 4種類のプレイヤーAIによる自動プレイ(約6分)
STAGES=200 node tests/balance.test.js # もっと先まで
npm install && node tests/ui.test.js  # iPhone SE / 13 / 14 Pro Max の画面で操作テスト(Playwright)
```

バランステストでは、プレイヤーAIが「予想勝率が低ければ直近のステージで稼いで強化 → 再挑戦」を繰り返し、
次のことを確かめています。

- 方針(相性を見て強化 / 欲しい強化をランダムに決めて貯める / 戦車だけ強化 / 放置中心)を変えても、どこかで永久に詰まらない
- 序盤(ステージ1〜10)は合計30戦以内
- 詰まっても前のステージで稼げば進める(最大の詰まり: 堅実40戦・ランダム60戦・相性無視150戦以内)
- 稼ぎ先のステージは十分勝てる(予想勝率40%以上)
- 進むほど詰まりが際限なく重くならない(20ステージごとの平均が8戦以内)
- 相性を見て強化するほうが早く進む / 生産施設と放置が役に立つ
- ステージ5000でも数値が壊れない
- 増援は枠の数まで両軍とも出る、手動ではポイントがたまるまで出せない、前進・後退でダメージが変わる
- 武装は研究所と設計図がないと開発できない、効果はそれぞれ攻撃力・耐久・苦手な敵へのダメージだけ、特殊は苦手の半分までしか打ち消さない
- プレイヤーAIは施設と同じ基準で武装も開発・強化する(戦車ひと筋のAIは戦車の武装だけ)

## ファイル構成

- `index.html` … ゲーム本体(これだけで動きます)。`<script id="logic">` がゲームの計算、`<script id="ui">` が画面と演出
- `tests/balance.test.js` … バランスの自動テスト
- `tests/ui.test.js` … iPhone 画面での操作テスト
