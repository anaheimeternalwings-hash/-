# 前線基地コマンダー

iPhone のブラウザで遊べる、一人用の軍事基地育成ゲームです。
**`index.html` の1ファイルだけ**で動きます(広告なし・外部との通信なし・日本語・縦画面向け)。

## 遊び方

1. **基地**: 3×3 の区画(中央が司令部)に施設を建てて強化します。費用は資金と鋼材。
2. **出撃**: 敵の編成を見て、相性の良い兵種と指揮官で部隊を組み、出撃します。戦闘は自動(×1/×2/×4・スキップ)。
   - **陣取り地図**: 出撃画面の上は六角形のマスでできた地図です。1段が1ステージで、制圧した段までが自軍の領土(緑)、
     その先が敵の領土(赤)です。マスをタップするとそのステージを選べます(まだ行けない段は選べません)。
     なぞると地図を上下に動かせます。新しいステージを初めて制圧すると、地図に戻ったときにそのマスが緑に変わる演出があります。
   - **画面のデザイン**: 暗い司令室のような「戦術HUD」風です。紺鼠の地に琥珀色の差し色、味方は青緑・敵は赤。パネルやボタンは角を切り落とし、
     四隅に括弧、数字は等幅です。下のタブには BASE / FORCES / ARSENAL / SORTIE の小さな英字。
     - 基地: 施設は暗いコンクリートの基礎に建つ立体的なミニチュア(窓の明かり・警告色の縞)で、設計図ふうの区画に並びます。
     - 指揮官10人と敵将6人の顔は描き下ろしのイラスト(半リアルのアニメ調、人物ごとの色の光)です。画像はファイルに埋め込んであり、
       通信はしません。小さい枠では顔に寄せて表示し、出撃画面の敵将の欄と戦闘中のスキルの帯にも顔が出ます。
     - 出撃の地図は暗い戦術マップで、六角形のマスに描き下ろしの地形の絵(草原・森・山・湖・砂漠・雪原・基地)を敷き、
       青緑の自軍の領土・赤い敵の領土を重ねます(次の目標は照準、選んだマスは琥珀色の枠)。
     - 兵器の画面の武器・防護・特殊(4兵種×3種類×6〜7段階)も、すべて描き下ろしの絵です。
     - 戦闘は低い角度から見た立体的な戦場です。遠くには空と山なみの地平線、奥ほどかすむ空気、高く盛り上がった丘(左上からの光と影)、
       陰影のある木。兵士と車両は部隊アイコンと同じ描き下ろしの絵(味方は開発した兵器、敵はステージの年代の姿)で、
       味方は青緑・敵は赤の光る縁取り(敵は左右反転)。引いた画面でも絵が見えるよう、1部隊は歩兵7人・対戦車兵5組・戦車3両・砲兵2門の大きな絵で描き、
       カメラは部隊を全部入れるときもある程度までしか引きません(端の部隊はなぞって見回すか、2本指で引くと見えます)。
       足元に影があり、六角形の兵種章と兵数の札は部隊の上に浮かぶ札(地面まで細い支柱)。
       爆発は閃光と火花・黒煙で、地面に焦げ跡がしばらく残ります。銃弾と砲弾は光の筋、ミサイルとロケットは煙の尾を引き、
       戦車・自走砲が動くと土煙が上がります。画面全体は奥が青く冷たく、手前が暖かい色合い。
       上部は斜めの目盛りつきの兵力バー。
   斜め上から見下ろした戦場で、兵士の群れ(部隊)が **マップ全体** を動き回り、出会った所で撃ち合います(戦う場所は決まっていません)。
   部隊の上の数字は残りの兵数です。敵を全滅させたらその場で勝利です。
   地形はステージによって草原・雪原・砂漠に変わります。
   - **広大な戦場と地形マップ**: 戦場は横幅が7列ぶん(列の番号は位置の目安)あり、地図の上に **森林・市街地・丘陵・湿地の区域** が自然な形で広がっています(それ以外は平原)。
     区域は戦場の真ん中にも、自軍側・敵側の奥にもあります(ステージごとに決まっていて、場所の名前で出やすい地形が変わります)。
     地形は立体的に描きます: 丘陵は盛り上がった丘(高さごとの段を積み重ね、左上から光が当たって右下に影)で、部隊や岩も丘の上に乗ります。
     森林は木が密集し、市街地は中心ほど高いビルが建ちます。丘陵はほかの区域と重なると丘陵が上になります。
     部隊は **実際にいる場所の地形** の効果を受けます:
     - 撃つとき・撃たれるときに、いまいる場所の地形で攻撃・守りが変わります(森や市街地で待ち構える敵は手ごわい)。
     - 進む速さも、いまいる場所の地形で変わります(湿地や森を通ると遅れる)。
     - 部隊が止まって戦い始めると「森林 守+30%」「湿地 攻-30% 被ダメ+20%」のように、その場所の効果が出ます。
     | 地形 | 戦闘の効果 | 移動の速さ |
     |---|---|---|
     | 平原 | 戦車の攻撃+20% | 戦車+30%・ほか+10% |
     | 森林 | 歩兵・対戦車兵の被ダメージ-30%、戦車の攻撃-15% | 戦車-45%・砲兵-35%・歩兵/対戦車兵-15% |
     | 市街地 | 歩兵・対戦車兵の被ダメージ-35%(歩兵は攻撃+10%)、戦車の被ダメージ+25% | 戦車-30%・砲兵-25%・歩兵/対戦車兵-10% |
     | 丘陵 | 攻撃+15%(砲兵は+35%)、被ダメージ-10% | -20%(戦車-25%) |
     | 湿地 | 戦車の攻撃-30%・被ダメージ+20%、砲兵の攻撃-15% | 戦車-55%・ほか-30% |

     部隊は近い敵をおもに狙い、遠い敵への攻撃は弱まります(砲兵は遠くても弱まりません)。
   - **射程**: 兵種ごとに、どれだけ離れた敵まで撃てるかが決まっています(列の幅を1とした距離。奥行きも同じ縮尺)。
     | 兵種 | 射程(半径) |
     |---|---|
     | 歩兵 | 2列 |
     | 対戦車兵 | 2.5列 |
     | 戦車 | 3列 |
     | 砲兵 | 戦場全体 |

     射程の外の敵は狙えません。射程内に見えている敵がいなければ、見えている敵へ近づいてから撃ちます(動いている間は撃てません。敵も同じ)。
     配置中や手動で部隊をドラッグしている間は、その部隊の射程が黄色い円で出ます。射程は「部隊」タブの兵種一覧でも見られます。
     部隊の枠は司令部の強化で最大8(敵もステージが進むと最大8部隊)。
   - **編成の上限**: 兵種ごとに編成できる部隊の数に上限があります(歩兵4・対戦車兵3・戦車3・砲兵2部隊まで)。
     全部同じ兵種のような偏った編成はできません(まだ兵種が少なく、ほかに置ける兵種がないときだけ超えられます)。
     編成画面では上限に達した兵種は選べず、おまかせ編成も上限を守ります。敵の編成も同じ上限を守ります(砲兵ばかりの敵は出ません)。
   - **戦闘時間**: 戦闘は最大3分です(画面右上に残り時間)。3分たっても決着しないと時間切れ(負け)です。
   - **動き方**: 部隊はマップ上を自由に動きます(平原での速さ: 戦車0.9列/秒・歩兵0.6・対戦車兵0.55・砲兵0.35。いる場所の地形の速さを掛ける)。
     - 見えている敵がいれば近づいて撃ち合い、見えている敵がいなければ前へ進んで探します。速い部隊が1部隊だけ先に行きすぎないよう、
       味方と足並みをそろえて進みます。砲兵は自分からは動かず、置いた場所から撃ちます。
     - 敵は地形の良い場所(森・市街地・丘など)に置いた部隊がそこで待ち構え、見つけた敵に向かってきます。
       そのため、森や市街地にこもった敵陣へ攻め込む戦いや、開けた平原でのぶつかり合いなど、マップの型で戦い方が変わります。
   - **敵の連携(作戦)**: 敵はステージごとに作戦を立て、部隊どうしが連動して動きます(どの作戦かは戦闘のあとの結果画面で明かされます)。
     | 作戦 | 敵の動き |
     |---|---|
     | 待ち伏せ | 地形の良い場所で待ち構え、見つけた敵に向かう |
     | 総攻撃 | 全部隊がそろって前進してくる |
     | 陽動 | 囮の部隊がまっすぐ正面に出て引きつけ、その間に別動隊が片側の端を回って後ろへ回り込み、後衛(砲兵・後ろの部隊)を襲う |
     | 挟み撃ち | 囮が正面に出て、左右の両端から別動隊が回り込む |

     - どの作戦でも、見えている自軍の部隊のうち倒しやすいもの(兵力の少ない部隊。砲兵は特に)を選んで **集中攻撃** します。
       自軍の部隊が敵の3部隊以上から撃たれると「集中攻撃を受けている!」、回り込んだ敵を見つけると「敵が側面から回り込んできた!」と出ます。
     - 回り込んだ部隊は、後ろに着くまでは後衛しか撃たずに進みます。砲兵の近くに歩兵や戦車を残しておくと守れます。
     - 増援は後方(占領した拠点があれば、いちばん前の前線基地)から出てきます。
   - **索敵(見える範囲)と見つかりにくさ**: 部隊ごとに索敵範囲があり、敵の部隊は自軍のどれかの部隊に見つかるまで見えません。
     敵からも同じで、こちらの部隊も敵に見つかるまで見えません。見えない敵は狙えません(射程が戦場全体の砲兵も、味方が見つけた敵しか撃てません)。
     敵が見える距離は「見る側の索敵範囲 × 見られる側の見つかりやすさ」です。
     | 兵種 | 索敵範囲(半径) | 見つかりにくさ(見つかる距離の倍率) |
     |---|---|---|
     | 歩兵 | 1.3列(偵察が得意) | 高い(×0.8) |
     | 対戦車兵 | 1.0列 | とても高い(×0.6。伏せて待ち構える) |
     | 戦車 | 0.9列 | 低い(×1.25。大きくて目立つ) |
     | 砲兵 | 0.6列 | ふつう(×1.1) |

     たとえば歩兵は戦車を1.3×1.25≒1.6列先から見つけられますが、戦車が対戦車兵に気づくのは0.9×0.6≒0.5列まで近づいてからです。
     見えるかどうかは味方全体で共有します(歩兵が見つけた敵を、後方の砲兵が撃てます)。距離は列の幅を1として、奥行きも同じ縮尺で測ります。
     - **攻撃している間は位置が見えます**(撃ってから2.5秒。撃ち続けている部隊は見えたまま)。敵からも同じで、撃った砲兵は敵に見つかります。
     - ただし砲兵が撃てるのは、味方の部隊が索敵範囲で見つけている(観測している)敵だけです。撃って位置がばれただけの敵は、
       近くの歩兵・戦車などは狙えますが、遠くの砲兵は狙えません。
     - 時間がたつだけでは見つかりません。**部隊を動かして探す** ことで見つかります。見えている敵がいないとき、部隊はマップを区画に分けて、
       まだ探していない区画を(敵の側を先に)手分けして探して回ります(敵が見えていない間の行軍は1.5倍の速さ)。
       動かない砲兵だけでは、離れた所に待ち構える敵は見つけられません。
     - 両軍の出撃線は索敵範囲より離れているので、配置中はどこに置いても敵は見えません(敵の兵種と数は出撃画面で見られます)。
       戦闘が始まって近づくと、見つけた敵が「発見!」で姿を現します。敵の増援も、見つけるまで位置はわかりません。
     - 配置中や手動で部隊をドラッグしている間は、その部隊の索敵範囲が水色の円で出ます。索敵範囲は「部隊」タブの兵種一覧でも見られます。
     - 敵の布陣はステージごとに地形に合わせて決まっていて、こちらの配置では変わりません。そのため、おまかせ配置は自分の側の地形だけで決まり、
       配置中の予想勝率は敵の布陣をいくつか想定した平均です(本当の布陣は使いません)。
     - 一撃必中・一斉射撃・爆撃要請・弱点看破と特殊ユニットも、見えている敵だけが対象です(見えている敵がいなければ待ちます)。
   - **戦闘前の配置(自由配置)**: 出撃すると戦場全体が映り、自軍の部隊を **自軍の側(マップの手前半分)の好きな場所** へドラッグして置けます。
     列の真ん中でなくても、列と列の間・前寄り・後ろ寄りなど、落とした場所にそのまま置かれ、戦闘はその場所から始まります
     (前に置くほど早く敵に出会います)。敵は敵の側の奥(配置の時点では見つからない所)に布陣します。
     配置中は地図の区域に名前が出ます。ドラッグ中は、置く場所の射程(黄色の円)と索敵範囲(水色の円)、
     「置く場所: 森林 守+30%」のようなその場所の地形の効果が出ます。予想勝率もその場で変わります。
     「おまかせ配置」で地形から自動で並べ直し(砲兵は後ろの丘、ほかは地形の良い場所)、「戦闘開始」でその配置のまま戦います
     (「次から配置を省略」にするとおまかせ配置ですぐ始まります。出撃画面の「配置: 戦闘前に配置する / 省略」でいつでも戻せます)。
   - **広大な戦場の見た目**: 両軍の陣地・道・村・池・林・拠点の旗がある広大なマップです。開始時は戦場全体を見せてから部隊に寄ります。
     - **マップの型**: 地形(森林・市街地・丘陵・湿地)の並び方はステージごとに変わります。型は9種類で、9ステージごとに全部が1回ずつ出て、
       となりのステージと同じ型にはなりません(左右の反転もあります)。

       | 型 | 戦場のようす |
       |---|---|
       | 地形が点在 | いろいろな地形が散らばる(ステージ1・2はこの型) |
       | 開けた平原 | 小さな森や村がぽつぽつあるだけ。戦車が走りやすい |
       | 縦にのびる尾根と森 | 縦長の尾根や森が戦場を区切り、間が回廊になる |
       | 中央の高地 | 戦場の真ん中に大きな丘(または町)。両翼に森や湿地 |
       | 戦場を横切る帯 | 湿地(または森)の帯が横一列に横切り、切れ目は1〜2か所だけ |
       | 両翼に森 | 両端に深い森や丘。真ん中は開けている |
       | 斜めの尾根 | 丘と森の連なりが戦場を斜めに横切る |
       | 市街戦 | 町の区画が戦場の真ん中に並ぶ |
       | 固められた陣地 | 片方の側(ふつうは敵の側)に丘と町が集まり、もう片方は開けている |

       出撃画面のステージ名の下に「マップ: 市街戦」のように型が出ます。
     - 道の曲がり方・横道の数・両軍の陣地の位置・敵陣の家・拠点の場所もステージごとに変わります。
     指でなぞると見回し、2本指で拡大・縮小できます(いちばん引くと戦場全体を見渡せます。右上の「戦況を追う」で元の視点に戻ります)。
     戦闘中のカメラは、自軍と見えている敵の部隊が全部入るように引いて映します。手動で移動を指示した部隊の行き先は点線で出ます。
     (村の建物は見た目の演出で、勝敗の計算には影響しません)。
   - **拠点の占領と前線基地**: 戦場には拠点が6か所(自軍側3・敵側3)あります。敵部隊を1つ撃破するたびに戦況が進み、
     手前の敵の拠点から順に占領します。占領した拠点は前線基地になり、
     - 増援の枠が1部隊増え、増援ポイントのたまり方が速くなります(増援はその拠点から出てきます)。
     - 特殊ユニットを1回発進できます: **AH-64 アパッチ**(攻撃ヘリ: 戦車を優先して対戦車ミサイル4発)、
       **A-10 サンダーボルトII**(対地攻撃機: 敵の全部隊を掃射)、**スイッチブレード**(自爆ドローン: いちばん攻撃力の高い敵に突入)。
       AUTO では占領のすぐあとに自動で発進し、手動では右下のボタンで好きなときに発進できます。
     逆に味方の部隊がやられると自軍の拠点を奪われ、敵が増援や特殊ユニットを使ってきます。
     敵を全滅させたらその場で勝利です(勝利後の進軍はしません)。予想勝率にも拠点の効果が含まれます。
   - **大軍どうしの戦い**: 各部隊は数千人規模の兵士の群れで、どの敵を狙っているかが緑(自軍)・赤(敵)の線で見えます。
     両軍とも配置した場所からそのまま動き出します(最初に川や橋を渡ることはありません。前線の線や土のうの壁もありません)。
     重なった部隊は少し離して描きます。敵陣の家や見張り塔は、砲撃が続くと壊れて燃えます。
     指揮官「雷門 ハヤト」の一斉射撃は、後方の陣地からのミサイル攻撃になります。
   - **自動 / 手動の切替**: 出撃画面の「戦闘 自動/手動」か、戦闘中の「AUTO」ボタンでいつでも切り替えられます。
     手動では、自軍の部隊から敵の部隊へドラッグ(またはタップ→敵をタップ)すると、その敵を集中攻撃します。
     指揮官スキルは画面下のボタンで好きなタイミングで発動します
     (手動では押さないと発動しません)。予想勝率は自動戦闘の場合の値です。
   - **移動の指示(手動)**: 自軍の部隊を何もない場所へなぞると、マップ上のその場所へ移動し、着いたらそこで守ります
     (射程内の見えている敵だけ撃ち、自分からは探しに行きません)。部隊の上の「守」が移動の指示中のしるしです。
     敵へなぞると攻撃の指示に変わり、AUTO に戻すと解除されます。
     部隊をなぞっている間と指を離してから2秒は視点が動かないので、狙った場所がずれません(丘の上でも指を離した地点にそのまま届きます)。
   - **敵将(敵の指揮官)**: ボス戦(ステージ12以降)と、ステージ12からの3割ほどのステージに敵将がいます。敵将は1人で戦況をひっくり返すほどのスキルを持ち、
     出撃画面の敵部隊の下に「敵将「亡霊」 スキル〈亡者の行進〉: …」のように出ます(敵将の部隊には赤い「将」の印)。
     | 敵将 | スキル | 効果 | 出てくるステージ |
     |---|---|---|---|
     | 亡霊 | 亡者の行進 | 倒された敵の部隊をすべて兵力50%でよみがえらせる | 12から |
     | 鉄壁 | 不落要塞 | 12秒間、敵全体の被ダメージを5分の1にし、兵力を25%回復する | 12から |
     | 雷帝 | 戦術ミサイル | 自軍がいちばん集まった場所(半径1.6列)の部隊すべてに、兵力の50%のダメージ | 25から |
     | 毒蛇 | 電子妨害 | 12秒間、自軍の索敵がすべて使えなくなる(敵がまったく見えず、撃てない) | 40から |
     | 魔女 | 寝返り工作 | 自軍のいちばん強い部隊(指揮官のいない部隊)を寝返らせ、敵にする | 55から |
     | 死神 | 斬首作戦 | 指揮官のいる自軍の部隊すべてに、兵力の60%のダメージ | 70から |

     敵将の部隊は耐久の高い親衛隊(耐久3倍。その分ほかの敵部隊は弱くなり、全体の強さは変わりません)で、**敵陣の奥の本陣で動かずに構えます**。
     スキルは戦闘開始から5〜10秒ほどで最初に使い(亡霊は倒された部隊が出てからの10秒ほど)、その後は35〜45秒ごとに使います。**発動の4秒前に予告** があり、
     「敵将「雷帝」 戦術ミサイルを準備中」と出て、敵将のまわりに赤い輪と「発動まで 6.3」の残り秒数が出ます。予告中は敵将の位置が見え、
     **予告中に倒せば発動しません**(AUTO の部隊は予告中の敵将を優先して狙います。手動では敵将へドラッグして集中攻撃)。
     本陣は奥にあるので、止めるには砲兵(見えている敵なら戦場全体に届く)や指揮官のスキルが頼りです。
     互角の戦いではほぼ必ず、自軍がかなり強い戦いでも半分以上の戦闘でスキルが発動します。
   - **途中参戦(増援カード)**: 戦闘中は増援ポイントが少しずつたまり、たまると画面下のカードで予備の部隊を戦場に呼べます。
     タップするとおまかせの場所に、戦場へドラッグすると置いた列の後方に出ます。増援の数は司令部レベルで1〜3部隊
     (Lv1:1・Lv5:2・Lv10:3)、強さは通常の部隊の6割です。敵もステージ6から増援を出してきます。
     AUTO のときは、生き残っている敵に相性の良い兵種が自動で出ます(予想勝率にも増援が含まれます)。
   - **回収の演出**: 基地で生産施設の「回収」を押すと、資金・鋼材が上の表示へ飛んでいきます(戦闘後のコイン集めの演出はありません。勝つとすぐ結果が出ます)。
   - 戦闘の途中で閉じた場合、開き直すと残りは自動で戦った結果が反映されます。
3. **兵器**: 研究所を建てると、兵種ごとに武装を開発・強化できます(下の「兵器」タブ)。
   - 各兵種に **武器**(攻撃力 +5%/Lv)・**防護**(耐久 +5%/Lv)・**特殊**(苦手な敵へのダメージ)の3系統があります。
   - 5レベルごとに新型を**開発**します。名前は実在の兵器・装備から取っています(おおむね年代順。性能はゲーム用の数値)。
     - 戦車の武器: 75mm M3戦車砲 → 88mm KwK36 → 105mm L7 → 120mm L44 → 120mm L55 → 130mm Rh-130 → 改 → 改二…
     - 歩兵の武器: 三八式歩兵銃 → M1ガーランド → StG44 → AK-47 → M16A2 → HK416 → 20式小銃
     - 歩兵の特殊(対戦車): 九九式破甲爆雷 → M1バズーカ → パンツァーファウスト → RPG-7 → AT4 → ジャベリン
     - 対戦車兵の武器: ボーイズ対戦車銃 → パンツァーシュレック → M40無反動砲 → カール・グスタフ → TOW → コルネット → 中距離多目的誘導弾
     - 砲兵の武器: M101榴弾砲 → sFH18重榴弾砲 → M114榴弾砲 → FH70榴弾砲 → M777榴弾砲 → M270 MLRS → M142ハイマース
     - 防護は 防弾ベスト・装甲車・戦車の装甲・自走砲の車体、特殊は 機関銃・対装甲弾 など
   - 武装はそれぞれ実物を横から見た絵で表示され、新型を開発すると絵が変わります。
     **兵種のアイコンと戦場の見た目も開発に合わせて変わります**。兵種のアイコンは描き下ろしの絵で、
     新型2つ目までは第二次大戦、3〜4つ目は冷戦、5つ目からは現代の兵器になります(戦車は M4シャーマン → レオパルト1 → レオパルト2A6、
     歩兵は M1ガーランド → M16A2 → 現代の小銃と防弾装備、対戦車兵は バズーカ → カール・グスタフ → ジャベリン、
     砲兵は M101榴弾砲 → M109自走榴弾砲 → ハイマース)。
     敵のアイコンは左右反転して赤く光ります。
     敵のアイコンや戦場の見た目は、ステージが進むにつれて新しい年代の兵器になります(見た目だけで、強さには影響しません)。
     開発には **設計図** が必要で、設計図は戦闘に勝つと手に入ります(先のステージほど多く、ボス戦と初クリアは2倍)。
     開発と開発の間の**強化**は資金・鋼材だけでできます。武装のレベル上限は 研究所Lv×2 です。
   - **試作部品**: 2つ目以降の新型の開発には、そのレベル帯の試作部品が1個必要です(最初の型は設計図だけで「配備」できます)。
     試作部品は **10ステージごとのボス戦でだけ** 手に入り、ステージ10のボスは試作部品Ⅰ、20は Ⅱ、30は Ⅲ…と等級が上がります。
     2つ目の新型には Ⅰ、3つ目には Ⅱ … を使います(例: 戦車の主砲 88mm KwK36 → 105mm L7 の開発には試作部品Ⅱ)。
     ボスの初クリアで2個、それ以降も勝つとときどき手に入ります(内部の確率は10%。ゲーム画面には確率やレアドロップの表示は出しません。
     出撃した時点で決まるので、途中で閉じても変わりません)。
     部品は貴重なので、よく使う兵種の新型から開発するのがおすすめです。
   - **アイテム一覧**: 設計図と試作部品は画面に常には出さず、上のかばんのボタン(または兵器タブの「開発アイテム」)で
     必要なときに一覧を開きます。一覧には持っている数・手に入るステージ(部品はドロップするボス戦)・次に使う開発が出て、
     「集めに行く」「ボス戦へ」でそのステージへ移動します(設計図は勝率80%以上で稼げるステージ)。一覧の右上の ✕ は、下までスクロールしても常に見えています。
     各武装の必要素材(部品・設計図)をタップしても同じように移動します。ボス戦で部品を手に入れると、かばんに赤い印が付きます。
   - 特殊は苦手な相性を打ち消す装備です(歩兵の対戦車兵器 → 戦車に、戦車の機関銃 → 対戦車兵に、砲兵の対装甲弾 → 戦車に、など)。
     上げるほど伸びは小さくなり、苦手の半分を打ち消すところ(例: 戦車→対戦車兵 ×0.5 が最大 ×0.75)が上限なので、
     相性で編成を考える意味は残ります。
     戦闘では、特殊装備が効いた攻撃に「特効!」と出ます。
   - 武装は増援の部隊にも反映されます。ステージが進むと敵も武装の普及に合わせて少しずつ強くなります。
4. 勝てば資金・鋼材・設計図・経験値(ボス戦では試作部品も)。**負けても兵は失いません。** 勝てないときは前のステージで稼いで強化しましょう。
   - **稼ぎにおすすめ**: 負けたときの画面と出撃画面のボタンで、「予想勝率80%以上で勝てるステージのうち、
     1戦あたりの稼ぎ(勝率×報酬)がいちばん多いステージ」を探して、おまかせ編成にします。
     報酬2倍のボス戦が選ばれることもあります。

進行は自動で保存され、ブラウザを閉じて開き直すと続きから再開します(戦闘の途中で閉じても結果は反映されます)。
ターン数や期限による終了はなく、ステージは上限なく続きます。

## テスト

バランス確認と iPhone 画面での動作確認を自動テストにしています。

```sh
node tests/balance.test.js            # ルールの確認 + 4種類のプレイヤーAIによる自動プレイ(約2時間半。気まぐれなAIは3通りの乱数で調べる)
STAGES=200 node tests/balance.test.js # もっと先まで
npm install && node tests/ui.test.js  # iPhone SE / 13 / 14 Pro Max の画面で操作テスト(Playwright)
```

バランステストでは、プレイヤーAIが「予想勝率が低ければ直近のステージで稼いで強化 → 再挑戦」を繰り返し、
次のことを確かめています。

- 方針(相性を見て強化 / 欲しい強化をランダムに決めて貯める / 戦車だけ強化 / 放置中心)を変えても、どこかで永久に詰まらない
- 序盤(ステージ1〜10)は合計30戦以内
- 詰まっても前のステージで稼げば進める(最大の詰まり: 堅実40戦・ランダム60戦・相性無視150戦以内。
  ランダムは買う強化が乱数で大きく変わるので3通りの乱数で調べ、中央値60戦以内・どの乱数でも120戦以内)
- 稼ぎ先のステージは十分勝てる(予想勝率40%以上)
- 進むほど詰まりが際限なく重くならない(20ステージごとの平均が8戦以内)
- 相性を見て強化するほうが早く進む / 生産施設と放置が役に立つ
- ステージ5000でも数値が壊れない
- 地形の効果、近い敵をおもに狙うこと、おまかせ配置、戦闘の再現(手動の移動指示を入れても、少しずつ進めた結果が一括計算と一致)
- 編成の上限: 兵種ごとの上限(歩兵4・対戦車兵3・戦車3・砲兵2)をおまかせ編成も守る
- 敵の連携: ステージごとに作戦があり、挟み撃ちでは囮が正面に出て、別動隊が端を回って自軍の後ろまで来て砲兵を撃つ。敵の攻撃は1つの目標に集中する
- 敵将: ボス戦(12以降)と一部のステージにいて、6種類のスキル(よみがえり・不落要塞・戦術ミサイル・電子妨害・寝返り・斬首)がそれぞれ効く。
  発動の前に予告があり、予告中は位置が見え、倒せば発動しない。戦闘は最大3分。
  敵将は後方の本陣に構える親衛隊で、互角の戦いでは85%以上、自軍が1.5倍強い戦いでも50%以上の戦闘でスキルが発動する
- マップの型: 9ステージで9種類すべての型が出て、となりのステージとは違う型。型ごとに地形の形が違う(市街戦は町が多い・帯は横一列など)。拠点の場所も毎回違う
- 地形はマップ上の区域: 同じ列でも前後で地形が違い、いる場所の地形が効く
- 射程: 射程の外の敵は狙わず、射程内に敵がいなければ見えている敵へ近づく(動く間は撃たない)。砲兵は味方が見つけた敵なら戦場全体に届く
- 索敵: 兵種ごとに索敵範囲と見つかりにくさが違う(戦車は対戦車兵より遠くから見つかる)。配置の時点ではどこに置いても見えない。見えない敵は撃たない(両軍とも)。
  見え方は味方全体で共有。攻撃している間は位置が見える(砲兵は観測している敵だけ撃てる)。時間がたつだけでは見つからず、動かない砲兵だけでは見つけられない。部隊を動かして探せば、離れた所に隠れている敵も見つかる
- 移動: 部隊はマップ全体を動き、地形で速さが変わる(戦車は平原で速く湿地でとても遅い)。動いている間は撃たない。見えている敵がいなければ前へ探しに行き、
  敵陣の奥にこもった敵へはこちらから攻め込んで戦う(戦う場所は決まっていない)。砲兵はその場から撃つ
- 移動の指示: 手動のときだけ好きな場所へ動かせ、着いたらそこで守る。AUTO に戻すと解除
- 自由配置: 自軍の側の好きな場所(列の間・前後)に置け(範囲外は自軍の側に収める)、置いた場所から戦いが始まる。敵は配置の時点では見つからない奥に布陣する
- 敵部隊を撃破すると手前の拠点から占領し、増援+1と特殊ユニット1回を得る(両軍とも。決着後は占領しない)
- 増援は枠の数まで両軍とも出る、手動ではポイントがたまるまで出せない
- 新型の開発にはそのレベル帯の試作部品が要り、部品はその等級のボス戦でだけ出る(初クリア確定・以降は確率どおり)
- 武装は研究所と設計図がないと開発できない、効果はそれぞれ攻撃力・耐久・苦手な敵へのダメージだけ、特殊は苦手の半分までしか打ち消さない
- プレイヤーAIは施設と同じ基準で武装も開発・強化する(戦車ひと筋のAIは戦車の武装だけ)。
  試作部品は集める手間(平均10回のボス戦)を費用に含めて、どの新型に使うかを決める。
  部品だけが足りない開発が一番の候補のときは、詰まったタイミングでその等級のボス戦(勝率60%以上)を回って部品を集める

## ファイル構成

- `index.html` … ゲーム本体(これだけで動きます)。`<script id="logic">` がゲームの計算、`<script id="ui">` が画面と演出
- `tests/balance.test.js` … バランスの自動テスト
- `tests/ui.test.js` … iPhone 画面での操作テスト
- `tools/art/` … 描き下ろしの絵の元画像と、ゲームに埋め込むための道具(Python 3 + Pillow + NumPy)
  - `grid/` は何人分かをまとめて描いた画像(`grids.json` にどのマスが誰か・何かを書く。白い背景に2段に並んだ兵器も切り分ける)、
    `single/` は1枚ずつの画像(描き直しはこちらが優先)。`cfg.json` は顔の位置。兵器の絵(`a.兵種.武器/防護/特殊.番号`)と
    出撃の地図の地形タイル(`m.地形`)も、そろった組から描き下ろしの絵に替わります
