# 生成した絵(SpriteCook)

指揮官の顔(味方10人・敵将6人)と部隊アイコン(歩兵・対戦車・戦車・砲兵の開発段階ごと)を、
SpriteCook で生成した絵に差し替えるためのフォルダです。

- このフォルダの `*.webp` を `python3 tools/art.py embed` で `index.html` の `ART` に埋め込みます(data URL。1ファイルのまま、オフラインで動く)。
- `ART` に無い絵は、これまでのコードで描いた絵(Portrait・ArmArt)がそのまま使われます。少しずつ差し替えられます。
- 元画像の取り込み: `python3 tools/art.py add <キー> <元画像.png>`
  - 顔: `h:oni` / `e:ghost` など → 正方形に切って 256px の WebP
  - 部隊: `u:tank:3` など(背景が透明な味方の絵)→ 128px の WebP。青緑の部分を赤に塗り替えた敵の絵(`u:tank:e:3`)も作る
- 生成した絵の asset_id は `spritecook-assets.json` に記録します(`asset_id`・`sha12`・`label`)。

## 絵柄(HUD に合わせる)

- 背景・地: 暗い紺鼠(#0b1418 前後)。斜めの光、細い戦術グリッド
- 味方 #38d9b0(青緑)/ 敵 #ff4d4d(赤)/ 強調 #f5b83d(琥珀: 階級章・徽章)
- 顔: セミリアルなアニメ調の胸像、やや斜め向き、軍の身上書ふう。味方は青緑の輪郭光、敵将は赤い輪郭光と光る目
- 部隊: 横向き(右向き)のゲームアイコン、背景透明、なめらかな塗り(ピクセルアートではない)。
  車体・装備は実物に近い色(オリーブ・鉄)に、青緑のチームの印(帯・旗・マーク)を入れる(敵の絵はこの色を赤に塗り替える)

生成の設定: `pixel: false`(HD)、顔は `bg_mode: "include"`・1:1・512px、部隊は `bg_mode: "transparent"`・512px。
試作で決めた絵の asset_id を、残りの生成で `style_asset_ids` に渡して絵柄をそろえる。
