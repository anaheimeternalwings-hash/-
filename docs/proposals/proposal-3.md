# 企画書3: 「大きな戦役」の切り口

## 1. タイトルと、ひとことで言うと

**冬将軍 ― 大陸戦役**
1日で季節がひとつ進む大陸の地図で、補給の線をつなぎながら2週間かけて3つの敵国を落とす陣取り。

## 2. 30秒で伝わる説明

- 六角マスの大陸が舞台。南の小国から始めて、3つの敵国の首都を落としたら勝ち。
- 1回に進められるのは1〜3手番。1日で季節がひとつ、4日で1年が過ぎる。
- 軍団は「補給の線」が首都や補給基地までつながっていないと弱る。伸ばしすぎると冬に凍えて止まる。
- 逆に、敵の線を切って囲めば、戦わずに敵の軍団がまるごと消える。これがいちばん気持ちいい。
- 夏に敷いた鉄道が、冬に効く。3日前の自分の判断に、今日助けられたり泣かされたりする。

## 3. 1回の遊び(1〜3分)

| 時間 | すること |
|---|---|
| 0〜10秒 | 開くと大陸の地図。前回からたまった「手番」の数(最大8)と、いまの季節・残り日数が出る。 |
| 10〜25秒 | 地図を見る。補給の線(太い筆の線=十分、かすれた線=不足、線なし=孤立)と、敵について分かっていること(「北の敵将は冬に攻める構え・確かさ中」)を読む。 |
| 25〜50秒 | 命令を3つ出す。軍団をドラッグして進む先を決める/補充する/補給基地や鉄道を作る/空爆や偵察を使う。攻める前に「優勢・互角・不利」が出る。 |
| 50〜60秒 | 「進める」を押す。敵と自分が同時に動き、筆の矢印が走り、取ったマスに墨がにじんで色が変わる(約8秒)。戦いの結果が1行ずつ出る。 |
| 1〜3分 | 手番が残っていれば、もう1〜2手番くり返す。朝いちばんは3手番ほどたまっているので2〜3分、昼の合間は1手番で1分。 |
| 閉じる前 | 「次の手番まで あと2時間10分」「冬まで あと5手番」が出る。自動保存。 |

閉じているあいだに敵が勝手に攻めてくることは**ない**(理由は下の「出発点から変えたこと」)。

## 4. 陣取りのルール

### 盤面
- 横7×縦9の六角マス。うち陸が約48マス、残りは海。いまの地形タイル9種をそのまま使う(平地・森・山・川・町・工場・油田・港・首都などに当てはめる)。
- 自国は南の6マスから。敵国は3つ(それぞれ8〜10マス、敵将が1人ずつ)。残り約14マスはどこの国でもない土地。
- 大陸の形は「種の数字」から自動で作る。戦役ごとに違う大陸になる。

### 手番
- 手番は**3時間に1つ**たまる(最大8つまでためておける)。8手番=1季節なので、ふつうに遊ぶと**1日=1季節、4日=1年**。
- 1手番で出せる命令は**3つ**。軍団は最大5つなので、全部は動かせない。
- 命令の種類:

| 命令 | 中身 |
|---|---|
| 進軍・攻撃 | 軍団1つをとなりのマスへ(戦車は平地なら2マス、自国の鉄道の上は3マス) |
| 補充 | 軍団の兵力を+3(物資を使う。補給が届いているマスでだけ) |
| 建設 | 補給基地(3手番かかる)/鉄道(1手番に1マス)/陣地(守りが上がる) |
| 作戦 | 空爆(敵の補給基地を2手番止める)/偵察(見えない敵を3手番見る)/空輸(孤立した軍団を1手番だけ持たせる)。季節に各1回 |

- 「進める」を押すと、敵も同時に動く。敵の動きは押すまで見えない。

### 軍団と戦い
- 軍団は最初3つ、最大5つ。1つに指揮官1人(いまの10人)。兵種は歩兵・対戦車兵・戦車・砲兵の4つ(いまの三すくみを使う)。兵力は1〜10。
- 戦いの強さ = 兵力 × 兵種と地形の相性 × 補給 × 季節 × 指揮官。守る側は山・川・陣地で上乗せ。運のぶれは±1割だけ。
- 負けた側は兵力を失って後ろへ下がる。**下がる先がなければ全滅**。

### 補給(このゲームの心臓)
- 補給のもとは首都と補給基地。そこから自分のマスをたどって何マス目かで、届く量が決まる。

| もとからの距離 | 2マスまで | 3 | 4 | 5 | 6以上 | つながっていない |
|---|---|---|---|---|---|---|
| 強さ | 100% | 80% | 60% | 40% | 20% | 攻撃できない。毎手番、兵力-2 |

- 鉄道の上は2マスで1マスぶんに数える。
- 孤立したマスは3手番で相手のものになる。敵も同じルール。

### 前線の長さ
- 敵ととなり合う自分のマスの数が「前線の長さ」。守備隊の数(6+町の数×2)を超えたぶんは守りゼロで、敵が来たら取られる。
- 画面には「前線 9 / 守備隊 8」と数字ひとつで出す。川や山の線で止めると前線が短くなる。

### 季節
| 季節 | 起きること |
|---|---|
| 春 | ぬかるみ。戦車の2マス移動なし。川が増えて渡れない |
| 夏 | 何もなし。攻めどき |
| 秋 | 収穫で物資が1.5倍。冬じたくの最後の機会 |
| 冬 | 補給が届く距離が2マス縮む。攻める側の強さ-2割。**川が凍って渡れる**(川で守っていた線が消える) |

### 勝ち負け
- 敵の首都を落とすと、その国はまるごと崩れる(残りのマスは2手番で手に入る。後片づけの退屈をなくす)。3つ落としたら勝利。
- 自分の首都が落ちたら敗北(戦役ごとに1回だけ「季節のはじめ」からやり直せる)。
- 期限は3年(12季節=96手番)。過ぎたら持っているマスの数で評価。早いほど高評価。

### 出発点から変えたこと
出発点は「放置で進む」だったが、**時間でたまるのは手番だけ、世界は自分が押したときだけ進む**形にした。理由は3つ。寝ているあいだに負けていたら腹が立つ。「何もしないのが得」な時間をなくせる。時計に頼らないので、自動プレイで同じ戦役を何百回も試せる。「数日あとに効く」はそのまま残る。

## 5. 面白さの核

### 毎回迷うこと
**「いま進むか、線を固めるか、敵の線を切りに行くか」**。命令は3つしかない。

- 進めばマスは増えるが、補給は細り、前線は長くなる。
- 鉄道や補給基地は、作っている数手番のあいだ何も得がない。効くのは次の季節。
- 敵の後ろに回りこむのは、失敗すると自分が囲まれる。

### 具体的な場面
- **3日前の自分に助けられる**: 夏の終わり、マスを取るのを我慢して北の峠まで鉄道を敷いた。秋に補給基地が完成。冬、敵の戦車軍団は雪で補給が2割まで落ちて止まる。こちらは鉄道のおかげで8割のまま峠を越え、敵のうしろの町を1つ取る。敵の軍団3つの線が切れ、3手番後にまとめて消える。戦ったのは1回だけ。
- **3日前の自分に泣かされる**: 夏に調子よく6マス進んだ。秋に「前線 13 / 守備隊 8」。冬、頼りにしていた川が凍り、敵が横から渡ってきて根もとの1マスを取る。先頭の2軍団が孤立。空輸で1手番だけ持たせて、助けに行くか、見捨てて首都を守るかを選ぶ。
- **読み合い**: 季節のはじめに敵将ごとの「ねらい」が、確かさつきで届く。「東の敵将は油田をねらう・確かさ低」。偵察を使えば確かになるが、季節に1回きり。同時に動くので、守りを寄せた裏を突かれることもあるし、空いた首都を逆に突けることもある。
- **逆転**: 負けていても、敵は伸びるほど補給が細る。押しこまれた冬に、伸びきった敵の根もとを1マス切れば、ひっくり返る。

### 「自動で眺めるのが最善」にならない理由
- そもそも自動がない。命令を出さなければ軍団は動かず、期限だけが減る。
- 戦いは一瞬で決まり、見どころは戦いの中ではなく**地図の上の3つの命令**にある。手を出すこと自体が遊び。
- 「とにかく前へ」も「ひたすら守る」も負けるように数字を合わせる(10章で測る)。

## 6. 長く遊べる仕組み

| 期間 | 変わること |
|---|---|
| 1日 | 季節がひとつ進む。季節のはじめに参謀が出す3つの作戦目標から1つ選ぶ(例「冬までに峠を取る」「前線を8以下にして冬を越す」)。達成で物資や作戦の回数が増える |
| 1週間 | 約2年ぶん。敵国が1つ崩れるか、こちらが大きく押し返されるか。地図の色がはっきり変わる |
| 2週間前後 | 1つの戦役が終わる。評価(早さ・失った兵力・囲んで消した数)と勲章 |
| 1か月 | 2〜3戦役め。新しい大陸と「くせ」が出る(冬が2季節つづく/島が多く港が大事/敵国が4つ) |

- **引きつぐもの**: 指揮官が戦役をまたいで特技を1つずつ覚える(「冬でも攻撃が落ちない」「鉄道を1手番に2マス敷く」)。10人ぶんあるので、誰を連れていくかで戦い方が変わる。
- **集めるもの**: 勲章(「冬に首都を落とす」「一度も孤立させない」「3軍団を一度に囲む」など約20個)。
- **戦史**: 終わった戦役は、季節ごとの前線が重ねて描かれた1枚の地図として残る。自分の2週間がひと目で見える。
- **区切り**: 季節(1日)・年(4日)・戦役(約2週間)。やめどきと再開の目印がはっきりしている。

## 8. 絵と音

### 流用できる絵(新しく描かなくてよい)
地形タイル9種(盤面)、指揮官10人と敵将6人の顔、部隊の絵(軍団のコマ)、航空機3種(空爆・偵察・空輸)、基地の施設(補給基地・工場のしるし)。絵柄がすでにそろっているのが強み。

### 新しく要る絵(Gemini で5枚、まとめ描き)
| 枚 | 中身 | 切り分け |
|---|---|---|
| 1 | 雪をかぶった地形タイル | 9個 |
| 2 | 地図のしるし(首都・補給基地・鉄道・橋・港・陣地・凍った川・孤立の印) | 8〜9個 |
| 3 | 季節の絵(春・夏・秋・冬) | 4個 |
| 4 | 勝利・敗北・戦役の表紙・国が崩れる場面 | 4個 |
| 5 | 勲章 | 20個 |

1日の上限内で足りる枚数。補給の線・矢印・にじみは絵ではなく Canvas で筆ふうに描く(太さとかすれで強さを見せる)。

### 音
- 命令を出す: 判子を押す音。矢印を引く: 筆がこすれる音。
- 「進める」: 低い太鼓がひとつ。マスを取る: 短い和音。取られる: 低くにごった音。
- 囲んで消す: 太鼓の連打のあと無音(ここだけ特別あつかい)。
- 季節が変わる: 鐘。冬のあいだは、うすい風の音。

## 9. 第1版 / 後回し / 難しい所

**第1版で作るもの**: 大陸1つ(自動生成)、敵国3つ、軍団5つ、命令4種、補給・前線・季節のルール全部、季節の作戦目標、評価と勲章10個、手番がたまる仕組み、流用絵での画面A〜D。

**後回し**: 2つめ以降の大陸の「くせ」、指揮官の特技の引きつぎ、戦史の地図、残りの勲章、新しい絵の3〜5枚め。

**いちばん難しい所**
1. **敵の頭**。弱いと作業、強すぎると理不尽。「ねらいをほのめかしてから動く」「伸びすぎた所を突く」を、決まった手順で書き、自動プレイで合わせる。
2. **小さい画面で補給をひと目で分からせる**。数字ではなく線の太さとかすれで見せる。ここが読めないとゲームにならない。
3. **大陸の自動生成**。峠・川・橋など「ここを取れば切れる」場所が毎回3〜5か所できるようにする。

**失敗しそうな所**
- **待たされて退屈**。3時間に1手番がじれったい恐れ。初日は手番を16個わたして2季節ぶん一気に遊べるようにし、間隔は数字1つで変えられるようにしておく。
- **最初の1分で面白さが出ない**。派手さがなく、面白さが出るのは最初の冬(2日め)。初日のうちに小さな「囲んで消す」を1回体験させる導入を作る。
- **終盤の消化試合**。首都を落とせば国ごと崩れるルールで防ぐが、測って確かめる。

## 10. 面白さの確かめ方

### 作る前(ルールだけを Node で動かす。画面なし)
4種類のプレイヤーAIに各500戦役やらせる。

| 測るもの | 合格の目安 | 何が分かるか |
|---|---|---|
| 「何もしない」の勝率 | 0% | 放置が得にならない |
| 「とにかく前へ」の勝率 | 20%以下 | 伸ばしすぎが罰される |
| 「ひたすら守る」の勝率 | 20%以下 | こもるのも負け |
| 「補給を考える」の勝率 | 60〜75% | 考えれば勝てるが、楽勝ではない |
| 上の2つと「考える」の差 | 40ポイント以上 | 判断が結果を決めている |
| 1戦役の長さ(まん中の値) | 60〜90手番(8〜11日) | 長すぎ・短すぎでない |
| 優勢と劣勢が入れかわる回数 | 1戦役に2回以上 | 逆転がある |
| 囲んで消す・消される回数 | 1戦役に合わせて3回以上 | 見せ場が起きている |
| 冬の攻撃の成功率 | 夏より20〜30ポイント低い | 季節が効いている |
| 「どの命令でも結果が変わらない手番」の割合 | 15%以下 | 押すだけの手番が少ない |
| マスの6割を取ってから勝つまで | 全体の4分の1以下 | 消化試合が短い |
| 運のぶれを変えて同じ手順でやり直したときの勝敗の一致 | 85%以上 | 運で決まっていない |

1つでも外れたら、絵や画面を作る前に数字を直す。

### 作った直後(依頼主に)
- 絵なしの仮の画面で、初日ぶん(16手番)を遊んでもらう。聞くのは2つだけ。「2日めも開きたいか」「取られたとき、なぜ取られたか分かったか」。
- 記録して見る数字: 1回の時間(1〜3分に入っているか)、命令を3つ使い切った手番の割合、攻める前の確認札を開いた回数(読んで迷っている証拠)。

## 11. ほかの案と比べたときの強みと弱み

**強み**
- いまの「前線基地コマンダー」と遊びが重ならない。あちらは戦いを眺める、こちらは地図で決める。両方あっても飽きない。
- 「手を出しても変わらない」問題が、作りからして起きない。
- 1回1〜3分・1日数回という遊び方に、進む速さがぴったり合う。途中で閉じても困らない。
- 絵の多くを流用でき、新しい絵は5枚。絵柄のずれが出にくい。
- 動きが少ないので、自動プレイでの確かめがしやすく、数字の合わせこみに時間を使える。

**弱み(正直に)**
- 地味。爆発も派手な戦闘もない。触った瞬間の気持ちよさは、すぐ戦える案に負ける。
- 面白さが分かるまで2日かかる。依頼主が初日に「つまらない」と言う危険がいちばん高い案。
- 1日に遊べる量に上限がある。もっと遊びたい日に遊べない。
- ルールの数が多い(補給・前線・季節・兵種)。説明を誤ると「わけが分からない」になる。
- 敵の頭の出来に全体がかかっている。そこが外れると全部が外れる。
