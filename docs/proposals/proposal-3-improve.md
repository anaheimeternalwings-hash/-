# 企画書3 改善案: 『冬将軍 ― 大陸戦役』を完成品に仕上げる

試作(`proto/fuyu/`)を実際に遊び、ルールのプログラムと自動プレイの数字を調べたうえでの改善案です。
いちばん大事な端末は **iPhone 16 Pro Max**(表示の広さ 440×763)として遊び・撮影・評価し、iPhone 13 と iPhone SE は「小さい画面でも崩れないか」の確認に使いました。

**この文書のまとめ(先に結論)**

- 骨組みは良い。自分で「裏のマスを先に取ってから攻める」と、敵の軍団がまるごと消える。この手ごたえは本物で、2戦役で3回、自分の手で起こせた。
- いちばんの弱点は **「何が起きたか分からない」** こと。結果の知らせが「マスを1つ取った」(差し引き)だけで、取られた場所も、戦いの勝ち負けも出ない。
- 次の弱点は **楽で、早く終わる** こと。2戦役とも26手番・32手番で最高の評価 S。冬を1回しか越さずに終わる戦役が多く(勝った戦役の73%)、題名の「冬将軍」がほとんど来ない。物資は余る(勝ったとき平均254)。
- 届いていない3つの目標のうち、**「冬の成功率」と「6割を取ってから勝つまで」は、小さなルール変更で合格した**(冬は敵国がみな攻勢に出る/冬は補給が3マス縮む/崩れた国の土地は中立に戻る)。
- **「勝った戦役の長さ」は、大陸を縦に2段広げて(7×11)57〜60手番まで伸びた**が、目標の60に届くか届かないかのところ。勝つまでの長さは「早く勝つ山」と「遅く勝つ山」の二こぶで、まん中の値が揺れやすい。目標の測り方を「冬を2回越して勝つ割合」に変えることを勧める(3章)。
- 16 Pro Max では地図の下に92ピクセルの空きがある。7×11の大陸にすると、この空きがちょうど埋まる(マスの大きさはほぼそのまま)。長さの対策と画面の対策が1つで済む。

## 1. 遊んでみた感想

### 1-1. 面白いところ

| 何が | 根拠 |
|---|---|
| **包囲して消すのが、自分で組み立てられる** | 1戦役目の4手番目: 自国に入りこんだ東の戦車(兵力6)の、ただ1つの退路(となりのマス)を歩兵で先に取り、そのあと戦車で攻撃 →「退路のない敵の軍団を包囲殲滅!」。5手番目にも同じ形でもう1つ。2戦役目の5手番目にも1つ。**命令の順番(1→2→3)がそのまま効く**ので、「先に退路を断つ」という考えが自然に生まれる |
| 攻める前の札が、判断に必要なことを一度に出す | 「見こみ: 優勢(強さの比1.47)/補給100%・相手: 戦車 兵力6(相性✕)/取ると前線 4→2」。迷ったときに読むと答えが出る |
| 補給の線が地図に描かれている | 補給の届き方が線の太さで見える。冬に線が点線になり、軍団の上に「補給20%」と出るので、冬の厳しさは目で分かる |
| 敵のねらいの予告が当たることがある | 1戦役目の最初の季節「毒蛇は補給線を狙い、南の町へ回りこむ」→ 3手番目に南の町を東の連邦に取られた。予告と結果がつながると「読み合い」の手ごたえがある |
| 絵がきれい | 墨の絵柄の部隊と指揮官の顔は、この画面の大きさでも映える。冬になると地形の絵が雪に変わり、季節が変わったことが一目で分かる |

### 1-2. つまらないところ

| 何が | 根拠 |
|---|---|
| **楽すぎて、早く終わる** | 1戦役目は32手番、2戦役目は26手番で勝ち、どちらも評価 S。自動プレイでも勝った戦役のまん中の値は38手番。勝った戦役のうち **冬を2回以上越したのは27%** だけ。題名の「冬将軍」が1回しか来ない |
| **物資が余り、使いみちに迷わない** | 自動プレイで16手番目(最初の冬)の物資は平均90、勝ったときは平均254。自分で遊んでも、最初の冬に84、勝ったとき162・214。補充や建設は「物資が足りるか」を考えなくてよく、決めるのは命令の数だけ |
| 使われない命令がある | 「補給を考える」自動プレイヤーの命令の内わけ: 移動63%・鉄道11%・補充8%・新しい軍団7%・空爆4%・空輸4%・補給基地3%・**陣地0%・偵察0%** |
| 敵が自分から袋に入ってくる | 敵は「命令を出す前の地図」で行き先を決め、こちらの命令のあとに動く。こちらが空けたマスに敵が入りこみ、次の手番に裏を取られて消える。最初の2〜3回は気持ちいいが、毎回同じ手で勝てる(自動プレイでも1戦役あたり敵の軍団6.5個が包囲や補給切れで消える) |
| 終盤が片づけになる | 2つ目の国が落ちたあと、残り1国を落とすまで平均10手番。2戦役目は最初の冬(16手番目)の時点で2国が崩れ、地図の72%が自国。冬は「残った1国が寒さで粘るのを待つ」時間になった |
| 新しい軍団を出せない場面がある | 首都に軍団がいると「首都が空いていない」で選べない。同じ手番でその軍団を首都から動かす命令を出していても選べない(ルールの中では、移動が先に済むので出せるのに) |

### 1-3. 分かりにくいところ

| 何が | 根拠 |
|---|---|
| **何が起きたか分からない** | 結果の知らせは「マスを2つ取った(自国12マス)」のような差し引きの数だけ。1戦役目の3手番目は、南の町(敵のねらいの場所)を東の連邦に取られたのに、同じ手番で1マス取っていたので **知らせが1行も出なかった**。2戦役目の冬も、西の王国に2マス取られ1マス取って知らせなし、選んでいた作戦目標「マスを1つも失わずに季節を終える」が黙って失敗していた。勝った戦いも知らせが出ない。元の企画書が聞くはずの「取られたとき、なぜ取られたか分かったか」に答えられない |
| 動きが速すぎる | 「進める」から0.9秒で動きが終わる。自分の命令と敵の動きが同時に流れ、どの軍団がどこから来たか追えない(元の企画書は約8秒の演出) |
| 地図の文字が重なる | となり合う孤立のマスで「孤立 あと2」の札が重なって読めない。崩れた国の首都にも「★首都」が残り、自国の色のマスに「首都」が2つ見える。敵のねらいの印「狙?」が同じマスに3つ重なる(200戦役のうち27で、最初の季節に3国のねらいが同じマス) |
| 最初の画面が文字の壁 | 開くといきなり「遊び方」の7段落。ここで読むのをやめる人が多いはず |
| 国の色が淡い | 東の連邦(緑がかった灰)とどこの国でもない草地の区別がつきにくい。冬は雪の白に淡い色が乗るだけで、3国の区別がさらにつきにくい |
| 説明の食い違い | 冬の攻めの弱まりが、季節の札では「-2割」、遊び方と攻める前の札では「-25%」(ルールは-25%) |
| 札の矛盾 | どこの国でもないマス(必ず取れる)へ動くとき「見こみ: 取れる」と「山で不利」が同時に出る |
| 包囲になるかどうかが札に出ない | 退路を先に断つと包囲殲滅になるのに、攻める前の札には退路のことが何も書かれていない。気づいた人だけが得をする |

### 1-4. iPhone 16 Pro Max で見たこと

| 何が | 根拠(測った値) |
|---|---|
| **地図の下が空く** | 地図の場所は440×560ピクセル、そのうち陸が使うのは上から467まで。**下に92ピクセルの空き**(地図の場所の16%)。iPhone 13 は47、SE は27 |
| 文字が小さいまま | 地図の上の文字(孤立・補給・狙?・建設中)は画面の大きさに関係なく10〜11ピクセル固定。マスの幅は57ピクセルあるのに文字はSEと同じ大きさ |
| 片手で届かない所 | メニュー(≡)が右上。6.9インチを片手で持つと親指が届かない。命令の欄と4つのボタンは下にあって押しやすい |
| 札の出る場所は良い | 攻める前の札は、狙うマスが上半分なら下の空きに出て地図を隠さない |
| 操作の手数 | 敵のマスへの移動は「軍団 → マス → 命令する」で3回、自国の中の移動は2回、建設・補充は3回。1手番はおよそ10回のタップ |

### 1-5. 「次の手番も遊びたい」と思えたか

- **序盤〜最初の包囲までは「はい」**。敵が入ってくる → 裏を取る → 消える、の流れは何度でもやりたくなる。
- **2つ目の国が落ちたあとは「作業」**。勝ちが見えていて、物資も軍団も足りている。冬が来ても怖くない(こちらは物資と鉄道で押し切れる)。
- 結果の知らせが弱いので、「進める」を押したあとの楽しみ(何が起きたかを見る時間)がない。ここが直れば、同じルールでも手応えはかなり上がるはず。

### 手番がたまる遊び方との付き合い方(S6の中身)

- **主にするのは「一気に」**。依頼主はいまこの遊び方で遊んでいて、1手番30〜60秒、1戦役は段階2のルールで約60手番=40分〜1時間。自動保存なので2〜3回に分けて遊べる。
- **「じっくり」は戦役のはじめに選べる別の遊び方**として残す。手番は3時間に1つ、最大8、はじめに16。段階2のルールで勝つまで約60手番なので、1日8手番ならおよそ8日。元の企画の「8〜11日」にちょうど合う。
- 途中で「じっくり」→「一気に」に切り替えるのは自由。記録には「一気に切り替えた」と残す。
- 閉じているあいだに敵が動くことはない(いまのまま)。
- ネット通信なしの1ファイルなので、「手番がたまりました」の通知は出せない。閉じる前の「次の手番まで あと2時間10分」の表示だけで、ホーム画面のアプリとして開いてもらう前提。

## 3. 届いていない3つの目標への対策(試した数値と結果)

### 3-0. 測り方

- 「補給を考える」自動プレイヤーで、1つの条件につき200戦役(最後の候補は400戦役を種の数字2組で)。種の数字の組が変わると、勝率は±3ポイントほど、長さのまん中の値は数手番揺れる。
- ルールのプログラムのコピーを作業フォルダに置き、試したいルールを切り替えられるようにして測った(元のファイルはそのまま)。いまのルールでは元の sim.js と同じ数字(勝率66%・38手番・14ポイント・31%)が出ることを確かめてある。
- 途中で、自動プレイヤー自身が弱点を持っていると分かったので、物資を使えるように直したもの(M8)でも測った。表では「直した自動プレイヤー」と書く。

### 3-1. 冬の攻撃の成功率(目標: 夏より20〜30ポイント低い。いま14ポイント)

**分かったこと**: 14ポイントの差は、**ほぼすべて敵の攻撃から来ている**。自国の攻撃の成功率は夏99%・冬99%で、冬でもまったく下がっていない。攻める前の見こみがほぼ正確(運のぶれは±1割だけ)なので、自動プレイヤーは勝てる攻撃しかしない。冬に変わるのは「攻められる回数」(夏の48%)であって、「攻めたときの成功率」ではない。人が遊んでも、見こみを読む人ほど同じことになる。

| 試したこと(1つずつ変えた) | 成功率の差 | 自国 夏→冬 | 敵 夏→冬 | 勝率 | 冬の攻撃回数(夏比) |
|---|---|---|---|---|---|
| いまのルール | 14 | 99→99 | 89→61 | 66% | 48% |
| 冬の攻める側の強さ 0.75→0.6 | 15 | 99→99 | 88→57 | 73% | 29% |
| 冬の補給の縮み 2→3マス | 19 | 99→96 | 90→50 | 63% | 20% |
| 冬の運のぶれ ±10%→±25% | 16 | 99→95 | 89→59 | 64% | 48% |
| 冬は敵が先に動く | 12 | 99→89 | 89→74 | 61% | 45% |
| 冬の霧(兵力は季節のはじめの値)+ぶれ±25% | 17 | 99→94 | 89→60 | 66% | 46% |
| 冬の守り(守る軍団×1.2) | 16 | 99→99 | 89→57 | 63% | 44% |
| **冬は敵国がみな攻勢に出る**(攻める基準を1.0に下げる) | **23** | 99→99 | 89→49 | 66% | 55% |
| **段階1: 冬の攻勢 + 冬の補給の縮み3マス + 崩れた国は中立**(400戦役×2組、直した自動プレイヤー) | **27〜28** | 99→100 | 89→39 | 70〜72% | 28% |

**採る案(M3)**: 「冬は敵国がみな攻勢に出る」+「冬は補給の届く距離が3マス縮む」。冬は「こちらが守りを固め、伸びきった敵の攻勢を跳ね返す季節」になる。元の企画の「押しこまれた冬に、伸びきった敵の根もとを切ればひっくり返る」とも合う。元の自動プレイヤーで測っても28ポイント・勝率62%で合格。

**正直に書いておくこと**: この案でも、自分の攻撃の成功率は冬に下がらない(99%→100%)。「自分が冬に攻めると失敗する」手ざわりまで欲しいなら、C1(冬の霧+運のぶれ±25%)を足すと自国の冬の成功率が95%前後に下がる。sim.js の数字は、自国と敵を分けて出すように直してほしい(M8)。

### 3-2. 6割を取ってから勝つまで(目標: 勝った戦役の4分の1以下。いま31%)

**分かったこと**: 1つ目の国が崩れた時点で、自国はもう地図の **約半分(51%)**。崩れた国の土地がまるごとこちらのものになるので、2つの国が残っているうちに6割を超えてしまう(勝った戦役の多くで、6割を超えたのは2つ目の国が崩れる前か同じ手番)。冬が終盤を引きのばしているわけではない(6割を超えてからの手番のうち冬は22%で、ふだんの割合25%と同じ)。

| 試したこと | 6割から | 勝率 | 長さ |
|---|---|---|---|
| いまのルール(崩れた国の土地はすべて自国に) | 31% | 66% | 38 |
| **崩れた国の土地は中立に戻る** | **18%** | 60% | 37 |
| 自国のとなりのマスだけ自国、残りは中立 | 24% | 67% | 35 |
| 講和(2国が崩れて6割を持てば、最後の国が降伏) | 17% | 70% | 32 |
| 講和の線を7割に | 22% | 68% | 33 |
| 国が崩れるたび、残った国の軍団の上限+1 | 38% | 35% | 42 |
| 首都の城壁(2回勝たないと落ちない) | 39% | 22% | 58 |
| **中立に戻す + 冬の攻勢 + 冬の縮み3マス**(400戦役×2組、直した自動プレイヤー) | **16〜17%** | 70〜72% | 39〜40 |

**採る案(M4)**: 崩れた国の土地は中立に戻す。後片づけの退屈は増えない(中立のマスは守りがなく、通るついでに取れる)うえ、「崩れた国の跡を、残った2国と取り合う」場面が生まれる。講和も効くが戦役がさらに短くなるので、長さの目標と両立しない。

### 3-3. 勝った戦役の長さ(目標: まん中の値で60〜90手番。いま38)

**分かったこと(試作者の見立ては当たっていた)**: 敵を強くしても、勝った戦役は長くならない。**長い戦役が勝ちから負け(期限切れ)へ移るだけ** で、勝ったものの長さのまん中は動かない。

| 試したこと(1つずつ) | 勝率 | 勝った長さ |
|---|---|---|
| いまのルール | 66% | 38 |
| 首都の守り ×1.5 / ×2.0 | 15% / 0% | 57 / — |
| 敵の軍団 2→3 | 21% | 42 |
| 命令 3→2 | 23% | 41 |
| 勝ちの線 1.25→1.4 | 68% | 39 |
| 敵の兵力の上限 8→10、敵の物資×2 | 66% | 38(まったく変わらない。敵は物資を使い切れない) |
| 首都のとなりを2マス取らないと首都を攻められない | 11% | 40 |
| 軍団の維持費 / 冬は命令2つ / 季節を6手番に | 66% / 54% / 64% | 40 / 35 / 32 |
| 7×11の大陸(元の自動プレイヤー) | 45% | 46 |
| **自動プレイヤーを直しただけ**(ルールは同じ) | **76%** | 38 |

もう1つ分かったこと: 元の自動プレイヤーの期限切れ(200のうち61)は、**61のうち50が、物資を300以上残し、軍団が5つ未満** のまま止まっていた。新しい軍団を出すには首都を空ける必要があるのに、それができない。勝てたはずの戦役が期限切れになり、勝ったものだけを数えると「早い勝ち」ばかりが残る。測る道具を直す(M8)のが先。

**組み合わせて試した結果**(直した自動プレイヤー、400戦役×種の数字2組):

| 案 | 勝率 | 勝った長さ(4分の1の点〜4分の3の点) | 冬を2回以上越して勝つ |
|---|---|---|---|
| 段階1: 冬の攻勢+冬の縮み3+崩れた国は中立(大陸は7×9のまま) | 70〜72% | 39〜40(32〜62) | 36〜37% |
| **段階2: 段階1 + 7×11の大陸 + 首都の守り×0.85 + 期限144手番** | **66〜67%** | **58〜59**(38〜78) | **53〜57%** |
| 段階2の冬を「冬の霧+ぶれ±25%」に替えたもの | 67〜69% | 57〜60 | 52〜59% |
| 段階2の冬を「冬の霧」の形にして、期限を128手番にしたもの | 64〜67% | 49〜59 | 50〜57% |
| 段階2を元の自動プレイヤーで | 62% | 46 | 44% |

**結論**:
- 段階2で58〜59手番。**目標の60に1〜2手番足りない**。勝つまでの長さは「40手番前後で勝つ山」と「70手番前後で勝つ山」の二こぶで(4分の1の点が38、4分の3の点が69〜78)、まん中の値はどちらの山に寄るかで大きく揺れる(冬の形や期限を少し変えたり、種の数字の組を変えたりすると49〜60)。
- そこで、**目標の測り方を変えることを勧める**: 「まん中の値で60〜90手番」の代わりに **「勝った戦役のうち、冬を2回以上越したものが半分以上」**(段階2で53〜57%、いま27%)。この遊びの山場は冬なので、冬を何回越したかのほうが「短すぎ・長すぎでない」をよく表す。実時間の長さは、S6の遊び方で決まる(「じっくり」なら約60手番=約8日で元の企画どおり)。
- 60手番に乗せたいなら、次に試すのは「首都の守り×0.8」「期限をさらに延ばす」「敵の頭(S3)」。どれも勝率が動くので、合わせ直しが要る(未検証)。

**副作用(注意)**: 7×11では「とにかく前へ」の負け方が「首都を落とされる(いま54%)」から「期限切れ(首都を落とされるのは0%)」に変わる。伸ばしすぎの罰が弱く見えるので、冬の攻勢が補給の細い軍団や首都を狙うようにする(S3、未検証)。
