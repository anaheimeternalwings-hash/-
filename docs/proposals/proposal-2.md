# 企画書2: 朱線(しゅせん)

## 1. タイトルと、ひとことで言うと何か

**朱線(しゅせん)** ― 親指1本で部隊を送り、5本の列で前線を押し合う、90秒の陣取り。

## 2. 30秒で伝わる説明

- 縦長の地図に列が5本。下が自分、上が敵。真ん中でぶつかった所が「前線」になる。
- 2秒に1つ部隊が届く。列をタップすると、その列へ走っていって戦う。
- 歩兵・戦車・対戦車兵はじゃんけんの関係。敵の先頭を見て、勝てる部隊を当てる。
- 1列だけ出すぎると横からも撃たれて、一気に崩れる。だから「わざと引いて、敵を出すぎさせる」が効く。
- 90秒たって、マスを多く持っている方の勝ち。敵の本陣に踏みこめばその場で勝ち。

## 3. 1回の遊び(1〜3分)で何をするか

| 時間 | すること |
|---|---|
| 0:00 | 開く。前回の続きの「戦区の地図」が出る。次の戦場が朱色で光っている |
| 0:05 | 戦場をタップ。敵将の顔と性格(「突っこんでくる」など)、地形が1画面で出る。「出撃」 |
| 0:10 | 開戦。最初の10秒は真ん中の空き地の取り合い。町のある列へ先に送るかを決める |
| 0:20〜1:10 | 押し合い。2秒に1回、どの列に送るかを決め続ける。ときどき列を下にはじいて「後退」 |
| 1:10〜1:40 | 残り30秒で太鼓が速くなる。指揮官の技(1回だけ)をどこで切るか。最後のマスの取り合い |
| 1:40 | 結果。星(最大3つ)、もらえた物、「崩した回数」。10秒 |
| 1:50 | 「次へ」「もう1回」か、そのまま閉じる |

戦いの途中で閉じても、その瞬間の盤面を保存する。次に開くと止まった状態で出て、「3、2、1」で再開する。

## 4. 陣取りのルール

**盤面**
- 列5本 × 段9つ = 45マス。いちばん下の段が自分の本陣、いちばん上が敵の本陣。
- 開始時は自分3段(15マス)、敵3段(15マス)、真ん中3段(15マス)は空き地。
- 地形は3つだけ。**町**(真ん中の空き地に3つ。持つと部隊の届く間隔が0.2秒ずつ縮む)、**丘**(そこで守る側は受ける被害3割減)、**川**(渡るのに1秒かかる)。

**部隊と補給**
- 部隊は2秒に1つ届き、画面下の「待機」に並ぶ(最大4つ。あふれたら届かなくなる=手を止めると損)。
- 届く順番は、戦いの前に決めた「編成」10部隊ぶんの袋から順に出る。次の3つが見える。
- 列をタップすると、待機の先頭がその列へ出発。1マス0.4秒で走る。**前線が遠いほど着くのが遅い**(押している側は増援が遅れ、押されている側はすぐ届く。これが逆転の土台)。
- 待機の2番目以降をタップすると、先頭と入れ替えられる。

**戦い**
- 各列で、両軍の先頭どうしが撃ち合う。体力100、与える被害は1秒に10。
- 相性がよいと被害1.5倍。歩兵→対戦車兵→戦車→歩兵。互角なら10秒、有利なら約7秒で決着。
- 1列に控えられるのは先頭+2つまで。先頭が倒れると控えが前に出る。控えがいなければ、相手が1.5秒に1マスずつ進んでくる。

**出すぎと総崩れ(このゲームの芯)**
- 自分の列が、隣の列より2マス以上前に出ていると、その横からも撃たれる(片側で被害1.5倍、両側で2倍)。地図の端は壁なので撃たれない。
- 出すぎた列で先頭が倒れ、控えがいないと、**隣の列の高さまで一気に取り返される(総崩れ)**。太鼓と画面の揺れで知らせる。敵にも同じことが起きる。

**後退**
- 列を下にはじくと、その列は1マス下がる。部隊は無傷で、3秒間は受ける被害が半分。1つの列につき8秒に1回。
- 敵は空いたマスに進んでくる → 敵が「出すぎ」になる → 両隣から挟める。

**指揮官の技**
- 1戦に1回。例:「一斉砲撃」(1列の敵すべてに50の被害)、「急行」(5秒間、送った部隊がすぐ着く)、「死守」(全列5秒間、被害半分)。

**勝ち負け**
- 敵の本陣の段に入り、3秒持ちこたえたら**突破勝ち**(敵が本陣から部隊を出して追い返せば不成立)。逆は負け。
- 90秒たったらマスの多い方の勝ち。同数なら町の多い方。

数字はすべて出発点で、自動プレイで直す前提。

## 5. 面白さの核

**毎回迷うこと: 「この1部隊を、どの列に送るか」。2秒に1回、90秒で約40回。**

届く部隊は足りない。5列すべてを支えるには1秒に0.6部隊ほど要るが、届くのは0.5。必ずどこか1列は捨てることになる。そこに次の3つの迷いが重なる。

1. **相性**: 左の敵は戦車。手元の先頭は歩兵、次が対戦車兵。歩兵を別の列に流して2秒待つか、入れ替えて今すぐ当てるか。
2. **押すか、引くか**: 中央が押されている。増援を足して粘るか、わざと後退して敵を出すぎさせ、左右を固めて挟むか。
3. **突破を狙うか**: 端の列は横から撃たれにくい。右端に3部隊つぎこめば本陣に届くかもしれない。そのあいだ他の4列は薄くなる。

**具体的な場面**
- **残り40秒、3マス負け。** 敵将は「突っこんでくる」性格。中央を下にはじいて1マス譲る。敵の戦車が進んできて、両隣より2マス前に出た。そこへ対戦車兵を送る。相性1.5倍 × 挟み撃ち2倍で3秒で溶け、控えのいない敵の中央が一気に2マス崩れる。太鼓が鳴って、マスの数が逆転する。
- **残り10秒、1マス勝ち。** 待機は歩兵1つだけ。左では自分の歩兵が瀕死、右では敵が町に手をかけている。左を守れば町を失い、右に送れば左が抜かれる。技「死守」を取っておいたかどうかがここで効く。
- **負け方がわかる。** 「欲ばって右端に送りすぎて、中央を挟まれた」と自分の口で言える。いまのゲームで困った「何が起きたかわからない」を、列5本・先頭1対1の見やすさで避ける。

**「眺めるのが最善」にならない理由**
- 自動で戦う機能がそもそもない。タップしなければ部隊は1つも出ず、20秒ほどで本陣に踏みこまれる。
- 逆の心配は「何も考えず連打するのが最善」になること。でたらめに送ると相性で負け、1列に集めると挟まれて崩れるように作り、10章の数字で確かめる。

**切り口から変えた所**
- 「長押しで流し込む」→「**1タップで1部隊**」。長押しは親指で画面が隠れ、兵種を選べず、効いた実感も薄い。1回のタップで駒が走り出して音が鳴る方が、「自分の手で動いた」とわかる。
- 「押す」だけでなく「**わざと引く**」を主役にした。押すだけの綱引きは、数字の大きい方が勝つだけになるため。

## 6. 長く遊べる仕組み

- **戦区の地図**: 架空の半島を南から北へ。1戦区=戦場10個+敵将との決戦。戦区ごとに地形の癖と敵将の性格が変わる(突っこむ・守りが固い・端ばかり狙う・町を先に取る、など6人)。
- **星3つ**: 勝つ/総崩れを1回以上起こす/突破勝ちか10マス差以上。取り直しができる。
- **編成**: 10部隊の袋の中身(歩兵4・戦車3・対戦車兵3など)と、指揮官1人を選ぶ。敵将に合わせて組み替える。
- **強化**: 勝つともらえる物資で兵種を強くする(体力や攻撃が数%ずつ)。**戦区ごとに上限**を決め、数字だけでは勝てないようにする。
- **今日の作戦**: 日付で決まる特別な3戦(「戦車が届かない日」「町が5つある日」など)。通信なしで毎日変わる。
- **放置の補給**: 開いていない間も物資が少したまる(最大8時間ぶん)。開く理由にはなるが、主役ではない。
- **勲章**: 「無傷の列を残して勝つ」「後退3回以上で勝つ」「残り5秒で逆転」など、遊び方を広げるお題。

| 期間 | 変わること |
|---|---|
| 1日 | 今日の作戦3戦+戦場を2〜3つ進める。計5〜6回、10分ほど |
| 1週間 | 第1戦区を突破、敵将1人を倒す。指揮官が3→5人に。編成を敵に合わせて変えるようになる |
| 1か月 | 3〜4戦区、敵将を半分以上倒す。部隊の見た目が次の年代に。星の取り直しと「難しい版」が残る |

## 8. 絵と音

**流用する絵**: 部隊の絵(歩兵・戦車・対戦車兵 × 3年代)、指揮官の顔10人、敵将の顔6人、地形タイル(平地・町・丘・川に当たるもの)。砲兵と兵器75種・基地の絵は第1版では使わない。

**新しく作る絵(Gemini で4枚。1日で足りる見込み)**

| 枚 | 中身 |
|---|---|
| 1 | 戦闘用の小さな駒: 3兵種を上から見た姿、走る・撃つ・倒れるの3つずつ(敵味方は色を変えて使い回す) |
| 2 | 本陣2種(自分・敵)、架空の旗印2種(丸と線だけの単純な形)、技の絵3つ |
| 3 | 戦区の地図の背景(墨で描いた半島の一部。縦長) |
| 4 | タイトルの絵1枚+結果画面の「勝利」「敗北」の筆文字 |

前線の筆の線、マスの塗り、煙、数字は絵を使わず画面に直接描く。朱色の差し色は自分の陣と前線だけに使い、絵柄をそろえる。

**音(すべて合成音)**
- 送り出し「トッ」、着いて撃ち合い始め「カッ」、マスを取ると半音ずつ上がる音。
- 出すぎの警告は低い太鼓の連打。総崩れは大太鼓+ざらついた音+画面の揺れ。
- 残り30秒から拍が速くなる。勝ち負けは短い笛。
- iPhone の Safari は振動が使えないので、手ごたえは音と揺れで出す。

## 9. 第1版で作るもの / 後回しにするもの

**第1版**: 戦闘のルール全部(5列×9段、3兵種、出すぎ・総崩れ、後退、技)、第1戦区(10戦場+敵将1人)、指揮官3人、編成、星、強化、途中保存、Node での自動プレイ。

**後回し**: 今日の作戦、勲章、放置の補給、第2戦区以降、年代の切り替え、砲兵と航空機、難しい版。

**いちばん難しい所**
- **敵の頭**: 敵も同じルール・同じ補給で動かす。性格ごとに「誘いに乗る/乗らない」を作り分け、ずるく見えず、弱すぎないようにする。
- **5列を一度に読める画面**: 小さい画面で、先頭の兵種・体力・控えの数・出すぎの危険が一目でわかること。

**失敗しそうな所**
- 忙しすぎて疲れる。2秒に1回が速すぎたら2.5秒に延ばす。
- 「相性だけ見て送る」で十分勝ててしまい、後退や挟み撃ちが飾りになる。
- 町を先に取った側がそのまま押し切る(逆転が起きない)。
- 押し間違い1回で負けて腹が立つ。列の幅と、送った直後の取り消しで手当てする。

## 10. 面白さの確かめ方

**作る前(画面なし、ルールだけを Node で)**: 腕前の違う5種類の自動プレイヤーに、同じ強さの敵と1000戦ずつさせる。

| 自動プレイヤー | 勝率の目標 | 外れたときの意味 |
|---|---|---|
| 何もしない | 0% | 眺めて勝てる=失格 |
| でたらめに送る | 15%以下 | 連打で勝てる |
| 1列だけに集める | 30%以下 | 突破が強すぎる |
| 相性だけ見る | 45〜60% | ふつうの人の位置 |
| 相性+後退+挟み撃ち | 75〜90% | 上手くなる余地がある |

あわせて見る数字:
- **後退を使う/使わないの差が10ポイント以上**(なければ「引く」が飾り)。
- 1戦の長さ: 中央値70〜90秒。40秒以内の決着は5%以下。
- **優勢が入れ替わる回数: 1戦に平均2回以上**。45秒時点で負けていた側の勝ちが20〜35%。
- 総崩れ: 1戦に1〜3回。0が多ければ地味、5以上なら大味。
- 5マス差以内の決着が4割以上。
- タップ回数: 1戦35〜50回。これを超える遊び方が最善なら忙しすぎ。

この表が満たせなければ、画面を作る前にルールを直す。

**作った直後(依頼主が5戦)**
- 負けたとき、理由をひとことで言えるか。
- 言われなくても「もう1回」を押したか(回数は端末の中に記録し、隠し画面で見られるようにする)。
- 片手で5戦続けて、指が疲れないか。
- 総崩れを起こした瞬間に「おっ」となるか。ならなければ音と揺れを直す。

## 11. ほかの案と比べたときの強みと弱み

**強み**
- 手を動かした結果が1秒以内に見える。いまのゲームでいちばん苦労した「手を出す意味」が、最初からゲームそのものになっている。
- 1戦90秒で終わりがはっきりしており、すきま時間に合う。
- 「引いて挟む」という、陣取りらしい読み合いが1つのルールで出る。逆転が起きやすい。
- 新しい絵が4枚で済み、いまの絵をそのまま使える。

**弱み**
- ながら遊びができない。90秒は画面から目を離せず、疲れている日は開く気になれないかもしれない。
- じっくり考えたい人には浅く見える。考える時間は2秒しかない。
- 基地を育てる、兵器を集めるといった「ためる楽しみ」は、いまのゲームよりずっと薄い。兵器75種の絵も使わない。
- 動きのあるゲームは調整が難しい。自動プレイの数字がよくても、指で触ると忙しい/ぬるいがありえるので、作った後の手直しは他の案より多くなる。
- 第1版は戦場10個で、中身の量は少ない。芯の90秒が面白くなければ、まわりを足しても救えない。
