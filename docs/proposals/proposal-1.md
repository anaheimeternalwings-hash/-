# 企画書1: 補給線を断て

## 1. タイトルと、ひとことで言うと

**『補給線を断て ― 十二手の戦場』**
1手ずつ交互にマスを取り合い、相手の陣地の「つながり」を切って、まとめて寝返らせる12手勝負の陣取り。

## 2. 30秒で伝わる説明

- 六角マスの小さな地図で、自分と敵将が1手ずつ交互にマスを取る。1局は12手ずつ、2〜3分。
- 陣地は本陣からつながっていないと生きられない。細い所を1マス切られると、その先が全部「孤立」する。
- 孤立した陣地は、次の自分の番でつなぎ直せなければ、まるごと敵のものになる。
- サイコロはない。押す前に「攻め3 対 守り2」と結果が全部見える。負けたら読み負け。
- 敵将にはそれぞれ癖がある。癖を読んで、先に切るか、切られる前に太くするか。

## 3. 1回の遊び(1〜3分)

| 時間 | すること |
|---|---|
| 0:00 | 開く。途中の対局があれば、その盤面からすぐ再開。なければホーム |
| 0:05 | 「今日の一問」(3手で勝つ詰め問題。30秒〜1分)か、「戦役」の次の戦場を選ぶ |
| 0:10 | 指揮官を1人選ぶ(前回と同じなら1タップ)。指揮官で、その局に使える切り札3枚が決まる |
| 0:15 | 対局開始。自分の手 → 敵の手(矢印つきで約1秒)を12回。1手に10秒ほど |
| 2:30 | 12手で終了。点数を数える演出(マスが1つずつ光る)。勝ち負けと星 |
| 2:40 | 「分かれ目の一手」を1枚で振り返る(形勢の折れ線と、いちばん差がついた手) |
| 2:50 | もう一局、または閉じる。いつ閉じても続きから |

時間がないときは「今日の一問」だけで1分。途中で閉じても1手単位で保存される。

## 4. 陣取りのルール

**盤面**
- 六角マス37個(横にいちばん広い所で7マス)。親指で押せる大きさ(1マス約50ポイント)。最初のほうの戦場は19マス・8手の小さい盤。
- 下の端に自分の本陣、上の端に敵の本陣。開始時はそれぞれ本陣と両隣の計3マスを持つ。
- 地形は3種類だけ: 山(入れない。3〜5マス)、森(守り+1。4マス前後)、町(守り+1、終了時に3点。3マス)。

**手番**
- 自分が先手、敵が後手。交互に12手ずつ。敵は後手のかわりに最初から1マス多い(この数は自動プレイで調整)。
- 1手でできるのは次のどれか1つ。
  1. **進む**: 自分の陣地に隣り合う空きマスを1つ取る。
  2. **攻める**: 自分の陣地に隣り合う敵マスを1つ奪う。成功の条件は下の「力くらべ」。
  3. **切り札を使う**: 1局に3枚まで(下の表)。

**力くらべ(運なし)**
- 攻めの力 = 狙うマスに隣り合う、自分のマスの数。
- 守りの力 = 狙うマスに隣り合う、相手のマスの数 + 地形(森・町+1、本陣+2)。
- 攻めが守りより**大きければ**奪える。同じなら奪えない(そもそも押せない)。
- マスを1回押すと「攻め3 対 守り2 → 奪える。切れるマス: 4」と下見が出て、もう1回押すと決定。
- つまり、**出っ張った陣地は弱く、へこんだ所に入り込んだ敵は取りやすい**。形がそのまま強さになる。

**補給線(このゲームの中心)**
- 自分のマスを隣どうしにたどって本陣に届くマスが「つながっている」マス。
- 届かなくなったマスは「孤立」。灰色に点滅し、攻めにも守りにも数えず、点にもならない。
- 持ち主の次の手番が終わっても孤立のままなら、**全部まとめて相手のマスになる**。
- 切られた側には1手だけ猶予がある。つなぎ直すか、見捨てて相手の別の線を切り返すか。

**切り札(第1版は5種。指揮官ごとに3枚の組み合わせが決まっている)**

| 切り札 | 効果 |
|---|---|
| 戦車突撃 | この手の攻めの力+2 |
| 砲撃 | 自分の陣地から2マス以内の敵マス1つを空き地に戻す(本陣以外) |
| 塹壕 | 自分のマス1つの守りをずっと+2 |
| 空挺 | 離れた空きマスを1つ取る。次の自分の番が終わるまでにつなげないと消える |
| 強行軍 | 1手で空きマスを2つ取る |

敵将も切り札を3枚持ち、残りは画面にずっと見えている。隠れた情報はない。

**勝ち負け**
- 敵の本陣を奪ったら、その場で勝ち(逆も同じ)。
- 12手ずつ終わったら点数勝負。マス1点、町3点。孤立中のマスは0点。同点は後手(敵)の勝ち。

## 5. 面白さの核

**毎回迷うのは「広げるか、太くするか、切りに行くか」。**
12手しかないので、3つ全部はできない。

- 広げる: 点は増えるが、陣地が細長くなり、切られやすい。
- 太くする: 切られにくいが、点が増えない1手になる。
- 切りに行く: 決まれば5マス一気に寝返る。ただし切るための出っ張りは、それ自体が弱い。

**具体的な場面**
残り2手、点数は14対17で負けている。敵は右側の町まで陣地を伸ばしたが、町とその先の5マスは、森の1マスだけで本陣につながっている。その森は守り3、こちらの攻めは2で届かない。ここで、8手目に使うか迷って温存した「戦車突撃」を使う。攻め4対守り3で森が落ちる。右側6マスが灰色に点滅する。敵は残り1手でつなぎ直したいが、つなげる空きマスは山にふさがれて1つもない。次の番の終わりに6マスと町がまるごとこちらの色に変わり、23対11で逆転。
逆の立場もある。「敵は砲撃を1枚残している。こちらの町への道は1マス幅。あの1マスを消されたら終わる」と気づいて、点にならない1手を道の横に打てるかどうか。

**読み合い**
- 敵将ごとに癖がある(第1版は3人)。「町にまっすぐ来る」「まず守りを固める」「細い所を見つけると必ず切りに来る」。対局前に顔と癖が1行で出る。癖を知っていると次の手が読め、読みが当たると気持ちいい。
- 敵の手は必ず矢印と数字つきで約1秒見せる。「なぜそこに打ったか」が後から分かる。

**手触り**
- 押す前の下見で、切れるマスが先に点滅する。「ここだ」と見つけた瞬間がごほうび。
- 寝返りは、マスが1つずつ「パタ、パタ、パタ」と色を変える。短いが、いちばん気持ちいい所にする。

**「自動で眺めるのが最善」にならない理由**
自動がない。12手すべてを自分で打ち、数字の育成もないので、勝敗を変えるのは自分の手だけ。前作でいちばん苦労した「手を出す意味」が、最初から100%になる。

**出発点から変えたこと**
- 囲碁のような「どこにでも置ける」はやめ、「自分の陣地の隣にしか進めない」にした。候補が毎手10〜20個におさまり、片手・10秒で考えられる。
- 「囲んで取る」のかわりに「補給線を切る」を中心にした。戦争らしく、「1マスで大きくひっくり返る」が初めての人にも一目で分かる。
- 手数を12手に固定した。時間が読め、「残り何手」が緊張になる。

## 6. 長く遊べる仕組み

数字を育てるゲームではない。育つのは自分の腕と、使える手札と、行ける戦場。

| 仕組み | 中身 |
|---|---|
| 戦役 | 架空の半島を南から北へ。5地方×6戦場=30戦場。戦場ごとに地形と敵将が違う |
| 星 | 戦場ごとに3つ。「勝つ」「町を全部持って終える」「本陣を落とす、または10点差」など |
| 指揮官 | 10人。星をためると加わる。人ごとに切り札3枚の組み合わせが違い、打ち方が変わる |
| 今日の一問 | 「3手で本陣を落とせ」などの詰め問題が毎日1問。日付から自動で作る。連続日数を記録 |
| 敵将 | 6人。地方が進むと、先まで読む敵将が出る。最後の敵将は勝率3〜4割を狙う |
| 段位 | 敵将相手の勝ち負けで上下する階級(10段階)。負けると下がる、正直な物差し |
| 遭遇戦 | 戦役を終えた後、毎回ちがう盤で好きな敵将と。連勝記録 |

- **1日**: 今日の一問+戦役を2〜3局。星が1〜3個増える。
- **1週間**: 1地方を抜ける。指揮官が1〜2人増えて「空挺で裏から切る」など新しい打ち方ができる。敵将の癖を1人覚える。
- **1か月**: 30戦場を一巡。星の取り残し埋め、段位上げ、遭遇戦の連勝、今日の一問の連続記録が残る。

放置でたまるものはない。開いたら必ず「考える1局」がある、という作りにする。

## 8. 絵と音

**流用できる絵(描き直さない)**
- 指揮官10人の顔、敵将6人の顔。
- 部隊の絵(歩兵=進む、戦車=戦車突撃、砲兵=砲撃、対戦車兵=塹壕)。航空機=空挺。
- 地形タイル(山・森・町に使う)。

**新しく必要な絵(Gemini で5枚。1〜2日分)**

| 枚 | 中身(まとめ描き) |
|---|---|
| 1 | 題字の背景: 墨で描いた作戦地図と、机に置いた駒 |
| 2 | 戦役の地図: 架空の半島の全体図(5地方) |
| 3 | 切り札の札5種+裏面1種(6つ並べる) |
| 4 | 勝ち・負け・本陣陥落の一枚絵(3つ並べる) |
| 5 | 段位の印10種(実在の階級章に見えない、筆の丸と線の組み合わせ) |

陣地の色分け、補給線、矢印、点滅は絵を使わず画面に直接描く。自分は差し色(朱)、敵はくすんだ藍、孤立は灰。墨のにじみ風の縁取りで、流用する絵と調子を合わせる。

**音(すべて合成音)**
- 置く:「コト」という木の駒の音。攻めて奪う: 低い太鼓1発。
- 孤立した: 短い警告の2音。寝返り: マスごとに「パタ」、枚数が多いほど音が上がっていく。
- 勝ち・負け: 2秒の短い節。対局中の音楽はなし(考えるじゃまをしない)。

## 9. 第1版で作るもの / 後回し

**第1版**
- ルール一式(37マス盤と19マス盤、12手、力くらべ、補給線、切り札5種)。
- 敵将3人(弱・中・強、癖つき)、指揮官4人。
- 戦役の最初の2地方(12戦場)、星、今日の一問、結果の振り返り、自動保存。
- 最初の3戦場は、遊びながら覚える案内つき(進む → 攻める → 切る、の順に1つずつ)。

**後回し**
- 残り3地方・敵将3人・指揮官6人、段位、遭遇戦、「待った」(1局1回の打ち直し)、追加の切り札と地形(川・橋)。

**いちばん難しい所**
- **敵の考える力**。弱すぎると作業、強すぎると理不尽。しかも「癖が読める」必要がある。盤が小さい(1手の候補が10〜20)ので、数手先まで全部調べる方法が iPhone でも1秒以内でできる。強さは「何手先まで読むか」と「何を大事にするか」で作り分ける。

**失敗しそうな所**
- **にらみ合い**: 両者が太く守り合うと、攻めが通らず動かなくなる。守りの数え方(上限をつける等)、切り札の枚数、町の点数で調整する。作る前に必ず自動プレイで確かめる。
- **毎回同じ打ち方**: 「最初に本陣へ突っこむのが最強」のような一本道ができると終わり。これも自動プレイで見つける。
- **地味**: 動きが少ないゲームなので、寝返りと本陣陥落の演出、盤面の墨の質感に手をかけないと「ダサい」と言われる。
- **疲れる**: 考えるゲームは負けが続くとやめたくなる。最初の地方は勝率7割以上になるよう、敵将を弱くする。

## 10. 面白さの確かめ方

**作る前(画面なし。ルールだけを Node で動かし、強さの違う自動プレイヤーどうしで各1000局)**

| 測るもの | 合格の目安 | 意味 |
|---|---|---|
| 深く読む側の勝率(3手読み 対 1手読み) | 75%以上 | 読みが報われる |
| でたらめ打ち 対 1手読み | でたらめの勝率5%以下 | 適当に押しても勝てない |
| 先手と後手の勝率(同じ強さ) | 45〜55% | 不公平がない |
| 1局で優勢が入れ替わる回数 | 平均1.5回以上 | 逆転がある |
| 補給切りで3マス以上寝返る局の割合 | 50〜80% | 見せ場が毎局のようにあるが、毎回ではない |
| 最後の3手で勝敗が動く局の割合 | 30%以上 | 最後まで緊張が続く |
| 1手の候補のうち「最善と大差ない手」の数 | 平均2〜4個 | 答えが1つでも、何でもよくもない |
| 最善手と平均的な手の差 | 平均3点以上 | 一手が重い |
| 本陣突撃だけを狙う打ち方の勝率 | 30%以下 | 一本道がない |
| 1手も攻めが成功しない局 | 5%以下 | にらみ合いで終わらない |
| 指揮官(切り札の組)ごとの勝率 | どれも40〜60% | はずれの指揮官がいない |

この表が合格するまで、画面は作らない。合格しなければ、ルールの数字を変えて測り直す。

**作った直後**
- 戦場ごとに、「依頼主くらいの腕」を想定した自動プレイヤー(2手読み、ときどき見落とす)の勝率を測る。第1地方70〜80%、第2地方50〜60%に並べる。
- 今日の一問は、答えが1通りであることを全問自動で確かめる。
- 実機で1局の時間(目標2〜3分)、1手の平均時間(目標15秒以下)を端末内に記録して見る。
- 依頼主には3つだけ聞く。「負けたとき、どの手が悪かったか自分で分かったか」「もう一局押したか」「見た目はどうか」。

## 11. この案の強みと弱み

**強み**
- 手を出す意味が最初から100%。前作でいちばん苦労した所が、この案では問題にならない。
- 1局の時間が読める(12手)。すきま時間に合い、途中で閉じても困らない。
- ルールが小さく運がないので、自動プレイで「面白さの数字」を作る前にはっきり測れる。
- 新しい絵が5枚で足りる。絵柄がばらつく危険が小さい。
- 「切った」「切られた」が一目で分かり、負けた理由が自分で分かる。

**弱み**
- 頭を使う。疲れているときに、ぼんやり眺めて楽しむことはできない。放置でたまる楽しみもない。
- 数字がどんどん増える気持ちよさ、基地が育つ楽しさはない。前作の基地や兵器75種の絵は使わない。
- 動きが少なく、見た目は3案の中でいちばん地味になりやすい。派手な戦闘を見たい人には物足りない。
- 敵の出来がすべて。敵がつまらない手を打つと、ゲーム全体がつまらなくなる。
- ルールの数字を外すと「にらみ合い」か「一本道」になる。作る前の自動プレイで合格しなければ、この案は捨てるべき。
